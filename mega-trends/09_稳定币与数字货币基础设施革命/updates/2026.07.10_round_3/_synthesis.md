## 0. 一句话裁定

**维持「积极关注」**；但**确定性重心从发行人层（Circle/USDC）迁移至基础设施层（Visa/Mastercard/BlackRock）**——支付三巨头下场是赛道级利好、发行人级利空，配置上必须分层。$900B 国库券需求口径修正为前瞻 2028 情景（当前实证仅 ~$200B）。

## 1. 头号裁定：支付三巨头 = 赛道利好 + 发行人利空（分层处理）

### 1.1 事件

2026.06.03，Stripe + Visa + Mastercard 被披露联合背书统一稳定币支付平台；Mastercard 收购 BVNK；Stripe-Bridge × Visa 计划扩展至 100 国可编程 Visa 卡；B2B 稳定币支付同比 +733%。

### 1.2 裁定

| 维度 | 判断 | 依据 |
|------|------|------|
| **赛道整体** | **利好**（催化 ★★★★★）| 合法化/主流化加速；稳定币嵌入全球受理网络；使用场景从投机扩展到真实支付/结算 |
| **基础设施/支付层**（V/MA/BLK）| **强利好** | 支付巨头从"潜在受损"转为"转型受益方"；BlackRock 是储备管理不可替代管道 |
| **发行人层**（Circle/COIN）| **结构性利空** | 巨头自建稳定币 → 发行人沦为商品化管道，净息差被竞争压薄；Forbes"可能击沉 Circle" |

### 1.3 配置含义

- 确定性层（核心）= Visa / Mastercard / BlackRock——无论平台选哪个代币，结算都过他们的网络
- 发行人层 = 降为高 beta / 估值保护，不当前价位重仓 Circle
- 采纳 PM 建议：CRCL 等 $40–50 或 08.11 财报后评估

**保守选择记录**：未采纳 B 的"微调上调"建议。理由：支付巨头挤压发行人 + GENIUS 推迟 + $900B 口径修正 + Circle 估值溢价四重因素抵消了上行催化。维持评级而非上调，是风险调整后的保守选择。

## 2. $900B 国库券需求口径修正

### 2.1 问题

README 基线"~$900B 结构性需求"易被误读为当前存量。

### 2.2 修正结论

| 维度 | 基线（R2）| R3 实证 |
|------|-----------|---------|
| 当前 T-bill 持仓 | 似为当前（$900B）| **实际 ~$200–230B**（Tether $141B + Circle $58B + 其他 $5–8B）|
| $900B 的性质 | 结构性需求 | **TBAC 建模上限 / Kansas City Fed "实质影响"阈值**——对应稳定币市值需达 $900B（当前 $310B，需再涨 ~180%）|
| 短端利率影响 | 隐含显著 | BIS WP 实测压低 3M T-bill **0.71 bps（即时）/ ~4 bps（10 日）**——**宏观可忽略** |
| 时间口径 | 不明确 | **$900B 是 2028–2029 前瞻情景**（Citi base case $1.6–1.9T 市场时）|

### 2.3 行动

**README 必须修正**：将"~$900B 结构性需求"明确标注为"**前瞻 2028 情景估值（TBAC 上限），当前实证 ~$200B**"。评级模型不得基于 $900B 当前存量假设。

**跨议题传导（#20）**：当前阶段利率影响可忽略；中期（2027–2028）若市值达 $500B–1T，将系统性压低短端 10–30 bps，形成"稳定币压短端 + AI CapEx 拉长端"的曲线陡峭化。

## 3. 确定性重心迁移：采纳为 R3 配置主线

### 3.1 迁移逻辑

C 主张确定性从发行人层（Circle/USDC）迁向基础设施层（Visa/MC/BlackRock）。**采纳**。

| 层级 | R2 隐含定位 | R3 裁定 | 迁移原因 |
|------|-----------|---------|---------|
| 发行人层（Circle）| 隐含主推 | 降为高 beta/估值保护 | 支付巨头挤压 + 利率敏感 + 银行代币化存款替代 |
| 基础设施层（V/MA/BLK）| 未明确 | **确定性核心** | 支付巨头转型受益 + 储备管道不可替代 |
| 交易所层（COIN）| 次推 | 高 beta 首选（优于 CRCL）| 收入多元（交易所+USDC 分成+Base L2）|

### 3.2 保守选择记录

未将 CRCL 列入确定性层。理由：(1) 公允价值 $35.82 vs 当前 $63–80 溢价 76–120%；(2) 支付巨头挤压概率 40%（魔鬼代言人）；(3) 利率下行直接压缩净息差。即使 USDC 增长强劲（+28%），估值风险高于基本面——这是保守选择。

## 8. 与 R2 的 Diff（评级/配置/口径变了什么、为什么）

### 8.1 Diff 总览

| 维度 | R2（05.25）| R3（07.10）| 变化原因 |
|------|-----------|-----------|---------|
| **评级** | 积极关注（隐含）| 积极关注（分层）| 赛道确定性↑，发行人确定性↓——维持总量但解耦 |
| **配置主线** | 隐含 Circle/COIN 主推 | **V/MA/BLK 确定性核心** | 支付巨头下场 + Circle 估值溢价 |
| **CRCL 定位** | 隐含主推 | **观望/估值保护（等 $40–50）** | 公允 $35.82 vs $63–80；支付巨头挤压 |
| **$900B 口径** | "当前结构性需求" | **前瞻 2028 情景（当前 ~$200B）** | Tether $141B + Circle $58B 实证；BIS 压低仅 0.71 bps |
| **头号风险** | Tether 黑天鹅 | **支付巨头挤压发行人** | Stripe/Visa/MC 下场（06.2026）；Tether 四大审计缓冲 |
| **GENIUS 时点** | 2026 中生效 | **2026 末–2027.01.18 法定生效** | NPRM 阶段拖长，法定 18 个月窗口 |
| **银行路径** | 预期"发行自有稳定币" | **代币化存款（TCH 联盟，2027H1）** | JPM/BofA/Citi/WFC 选防御性代币化存款 |

| **去美元化** | 威胁（隐含）| **降级（动能衰减）**，批发端待观察 | Foreign Policy "撞墙"；mBridge 批发端变量 |
| **新增假设** | — | H4（支付巨头主导结算）70%；H5（银行挤压）55% | 新结构性变化 |

### 8.2 关键 diff 解读

**最重要的三个变化**：

1. **配置主线迁移**（发行人→基础设施）：这是 R3 最核心的配置变化。R2 隐含 Circle/COIN 是主推标的，R3 明确 Visa/Mastercard/BlackRock 是确定性核心。原因：支付巨头下场使发行人层从"合规化受益方"变为"被挤压方"，而基础设施层反而是"转型受益方"。

2. **$900B 口径修正**：这不是小修正，而是防止评级模型基于错误量级。当前实证 ~$200B vs $900B 差 4.5 倍。若基于 $900B 当前存量假设做宏观利率判断，会严重高估短端影响。

3. **头号风险更新**：从"Tether 崩溃"（尾部、低概率）变为"支付巨头挤压"（进行时、高概率）。这改变了风险对冲的重点——从"防范 Tether 黑天鹅"转为"配置受益方对冲挤压"。

### 8.3 保守选择记录

| 决策 | 保守选择 | 理由 |
|------|---------|------|
| 不上调评级 | 维持"积极关注" | 支付巨头挤压 + GENIUS 推迟 + $900B 修正 + CRCL 估值四重抵消 |
| CRCL 不当前建仓 | 等 $40–50 | 估值溢价 76–120%；支付巨头挤压 40% 概率；利率敏感 |
| 银行股不纳入 #09 配置 | 时间线太远（2027H1）| 独立银行持仓更合适 |
| Tether 不可直接配置 | 非上市 + 尾部风险 | 通过减仓/避免 USDT 敞口间接对冲 |
