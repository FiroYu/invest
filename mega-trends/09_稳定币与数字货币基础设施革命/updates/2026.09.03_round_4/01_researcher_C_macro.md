# 宏观调研员 C 独立研究报告 — #09 稳定币

> 分析日期：2026-10-10 | 角色：macro | 信息截止 2026-10-10

## 一、核心发现（Top 3）

1. **利率体制对稳定币的净效应已翻转为"体制性压制"**：FOMC 9/16 加息 25bp 至 3.75-4.00%（12-0，点阵图暗示年底再 +25bp、2027 不降），10Y 一度 5.36%（10/1，2002 年来高位）。高利率对发行人是储备收益顺风，但（a）reserve return 下行斜率已现（Circle -66bps 至 3.48%——加息传导滞后+储备结构短化）；（b）对加密资产与高久期成长股（CRCL/COIN beta）的估值压制是即时且主导的；加密市值与稳定币市值同步三连流出。**宏观结论：利率通道从"双刃"变为"刃向外"**。
2. **稳定币与美元体系耦合加深的宏观证据链**：Fed 规则把储备法定锁进 93 天内 T-bill/现金/隔夜 repo（≈$213B 当前持仓+结构性增量）；Allium 口径下真实支付量 $401-527B（8 个月）≈零售跨境 0.31%；"去美元化"叙事进一步弱化——美元稳定币占 98%，欧盟 Qivalis（37 行）/香港牌照（HSBC/Anchorpoint）走的都是"法币合规化"而非"去美元"路线。mBridge 动能未见新催化（R3 已降级）。
3. **市值停滞的宏观解读——从"货币政策影子"到"支付流量池"**：$304B 平台期与利率高位并存，说明投机性铸造（2020-21、2024 模式）缺席，而支付/结算需求（Visa $20B+ 年化、B2B、汇款）是唯一增量引擎。**宏观范式**：稳定币进入"支付渗透率"定价阶段，beta 与 BTC 脱钩度上升（USDC 链上量 +151% vs 市值 -4.8% 是脱钩的直接证据）。

### 2.2 立法/监管宏观图谱

- **美国双轨**：GENIUS（发行）落地推进=确定性↑；CLARITY（市场结构）参院程序性失败（9/15，Trump 伦理让步救票未果）=加密交易/交易所监管悬置延续至 2027 国会会期。组合含义：发行/支付链条政策 beta 转正，交易/交易所链条政策 beta 仍负——**#09 与交易所标的（COIN 非纯交易所但部分暴露）应分开定价**。
- **监管套利窗口关闭**：Fed 反规避付息推定+Treasury 外国发行人 2028 硬执法日+州认证 $10B 线——离岸灰色发行人（含 USDT 现形态）的生存空间法定收窄，行业整合的宏观推力增强。
- **香港/欧盟**：香港首批牌照 4/10（HSBC+Anchorpoint）；欧盟 Qivalis 37 行 15 国、2026H2 发币。地缘格局=美元链（合规）+欧元链（银团）+离岸人民币轨道（mBridge，静默）——三极法币数字化，均非"去美元化"。
