# 议题09：稳定币与数字货币基础设施革命

> ## Round 3 综合裁定（2026.07.10，CIO 综合）
> **评级**：积极关注（维持，**分层处理**）
> **一句话判断**：支付三巨头下场 = **赛道级利好（合法化/主流化）+ 发行人级利空（商品化挤压）**——确定性重心从发行人层（Circle）迁移至基础设施层（Visa/Mastercard/BlackRock）。$900B 国库券需求修正为前瞻 2028 情景（当前实证仅 ~$200B）。

> **完整裁定**：[`updates/2026.07.10_round_3/_synthesis.md`](updates/2026.07.10_round_3/_synthesis.md)

## 核心判断（R2 基线，05.25）

GENIUS法案于2025年7月签署成为法律，标志着合规稳定币从灰色地带正式进入主流金融体系。稳定币总市值从5年前的~$5B飙升至~$290B（增长58倍），USDC季度链上交易量达$11.9T（同比+247%）。稳定币可能对国库券产生$900B级别的需求冲击，并从根本上重构全球支付基础设施。

**范式转移的核心逻辑：**
- **监管合法化**：GENIUS法案将稳定币发行人纳入联邦金融监管框架，消除合规不确定性
- **使用场景爆发**：从加密交易工具扩展到跨境支付、B2B结算、消费支付
- **国库券需求冲击**：稳定币发行人必须持有1:1美元储备（主要是国库券），可能创造$900B级别的新结构性需求
- **银行入场**：GENIUS实施后，大型银行（JPMorgan、Bank of America等）可能发行自有稳定币

## 争议与不确定性

### 银行体系存款外流风险
- 稳定币可能吸走商业银行存款，影响银行放贷能力
- 美联储和FDIC对银行参与稳定币的态度仍在演变
- GENIUS法案要求1:1美元支持，但允许的储备资产范围仍在讨论中

### 技术基础设施成熟度
- 区块链结算速度和成本仍不及传统支付网络（Visa每秒6.5万笔）
- Layer 2解决方案（Solana、Base、Arbitrum）正在缩小差距
- 合规工具（链上AML/KYC）仍在早期阶段

### 地缘政治维度
- 美元稳定币的全球扩张强化美元霸权，部分国家可能抵制
- 中国数字人民币（e-CNY）作为替代方案的进展
- 欧盟MiCA框架下的欧元稳定币发展

### Tether的合规风险
- USDT（Tether）占稳定币市场~60%份额，但合规透明度长期受质疑
- GENIUS法案可能迫使Tether大幅调整运营模式
- 若Tether出现问题，可能引发短期市场动荡

## 最新更新 — 2026.07.10（Round 3 CIO 综合）

### 评级：积极关注（维持，分层处理）

赛道级评级不变；但**确定性重心从发行人层（Circle/USDC）迁移至基础设施层（Visa/Mastercard/BlackRock）**。同一事件（支付三巨头下场）是赛道催化却是发行人威胁——必须分层。

### 头号裁定：支付三巨头 = 赛道利好 + 发行人利空

2026.06.03 Stripe + Visa + Mastercard 联合背书统一稳定币平台 + Mastercard 收购 BVNK + B2B +733%。

| 维度 | 判断 |
|------|------|
| **赛道整体** | **利好**（合法化/主流化加速，★★★★★ 催化） |
| **基础设施层（V/MA/BLK）** | **强利好**——从"潜在受损"转为"转型受益方"；BlackRock 是储备管理不可替代管道 |
| **发行人层（Circle/COIN）** | **结构性利空**——巨头自建稳定币挤压净息差，Forbes 称"可能击沉 Circle" |

### $900B 国库券口径修正（防误导）

README 基线"~$900B 结构性需求"易被误读为当前存量。**修正**：当前实证持仓仅 **~$200B**（Tether $141B + Circle $58B）；$900B 是 **TBAC 建模上限/前瞻 2028 情景**（对应市值需达 $900B，当前 $310B 需再涨 ~180%）。BIS 实测当前阶段压低 3M T-bill 仅 **0.71 bps（宏观可忽略）**。评级模型不得基于 $900B 当前存量假设。

| 情景 | 概率 | 稳定币市值 2027 中 |

### 三层组合配置

- **确定性层（50-60%）**：Visa 22% / Mastercard 18% / BlackRock 15%——无论平台选哪个代币，结算都过他们的网络
- **高 beta 层（25-35%）**：Coinbase 18%（首选，USDC 分成 $1.4B + Base L2 + 交易所多元）/ Circle 12%（**待建，等 $40-50 或 08.11 财报后**）
- **对冲层（5-15%）**：做空 Western Union / MoneyGram（商业模式被颠覆）+ 现金预留
- **规避**：Tether（非上市）/ Robinhood（加密收入 -47%）/ 银行股作 #09 配置（代币化存款 2027H1 太远）

### 头号风险更新（R3）

**从"Tether 黑天鹅"（尾部、低概率）更新为"支付巨头挤压发行人溢价"（进行时、高概率）**。改变了风险对冲重点——从"防范 Tether 崩溃"转为"配置受益方对冲挤压"。
