## 核心判断

从FinFET到GAA（Gate-All-Around，全环绕栅极）纳米片是晶体管架构自2011年FinFET引入以来最根本性的变化。背面供电（Backside Power Delivery）是另一层独立革命，将电源线从晶体管上方移到下方，释放布线空间并提升性能。TSMC N2已于2025Q4开始量产，良率65-75%（芯片级），2026Q1开始贡献营收。TSMC Q1 2026营收$359亿（+40.6% YoY），HPC平台占比从53%跳升至61%，AI驱动的收入结构质变已确认。ASML进入EUV超级周期——2026年60+台、2027年~90台（80 Low-NA + 10 High-NA）——设备商是确定性最高的受益者。2nm晶圆价格约$30,000，每晶体管成本改善仅~5%（vs N3的15%），摩尔定律经济回报递减趋势值得关注。Samsung SF2定价$20,000（低33%）但良率仅50-60%，尚未对TSMC构成实质威胁。Intel 18A Panther Lake已出货但"业界标准良率需2027年"，14A（2029年）与TSMC A14同期是中期关键变量。

**辩论评级：通过（维持）** — H1(HAA必经之路)/H2(EUV不可替代)维持95%信心；H4(每晶体管成本)从70%下调至55%，是本轮最显著的弱化项。

## 关注模型

- **ASML季度订单/EUV出货量**：最领先的行业晴雨表。ASML的订单积压和出货节奏反映全球先进制程投资的力度和确定性。
- **TSMC先进制程营收占比**：N3+N2占TSMC营收的百分比，当前74%，衡量先进制程的需求强度和客户买单意愿。
- **Intel代工良率进展**：Intel 18A的良率是Intel代工复兴的关键。"业界标准良率需2027年"意味着短期不构成威胁。
- **每晶体管成本趋势**：N2仅~5%改善是本轮最显著弱化项。如果N2P数据确认成本停止下降，将结构性改变投资叙事。
- **AI CapEx ROI**：Hyperscaler AI投入回报率是K3退场标准的核心驱动。
