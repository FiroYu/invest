## 三、共识与分歧

### 共识（所有角色一致认同）

1. **LLY是赛道王者**：Q1 $19.8B（+56% YoY）、市占率60.1%、Retatrutide 28.3% Phase 3数据、Foundayo处方增速超Wegovy口服——基本面无可争议
2. **口服GLP-1是真实需求**：Wegovy口服首季DKK 2.26B（~2x预期）、Foundayo第5周10,248周处方，口服消除注射壁垒的假设得到验证
3. **停药率是核心风险**：魔鬼辩护人提出、PM定性为"锚点风险"、A/C修订后确认。非T2D用户一年停药率65-75%远超30%假设
4. **NVO增长动能系统性弱于LLY**：2026指引仍为负增长（-4%至-12%）、CagriSema失败、管线真空期2-3年。PE 10x提供安全边际但非"世代级机会"
5. **HIMS不值得配置**：PM否决、A降至3/10、C未纳入。商业模式从高毛利创新降级为低毛利渠道
6. **Higher for Longer压制估值**：Fed 3.50-3.75%不降息，LLY PE 38x和NVO PE 10x均受利率环境影响

## 五、最可能的失败模式（采纳自魔鬼辩护人）

### #1：停药潮摧毁用户增长叙事（概率35-45%）

**描述**：口服GLP-1虽然降低了入门壁垒，但核心痛点（费用、副作用、心理倦怠）未解决。大量新用户涌入后在6-12个月内停药，活跃用户增长远低于处方量增长。

**触发信号**：
- Foundayo 6个月续方率低于40%
- 处方量增速维持但收入增速下滑（均价走低+高churn）
- Truveta首次处方率连续两月下降（K8）

**传导路径**：处方量增长但净收入增速放缓 → 分析师下调长期用户预测（3000万→1500-2000万） → LLY/NVO估值倍数压缩（PE从40x+降至25-30x） → 食品做空逻辑减弱

**CIO评估**：这是最应关注的失败模式。JMCP数据确认改善趋势（33%→61%），但非T2D用户65-75%停药率仍远超30%假设。PM正确指出三位研究员对此的重视程度不够。采纳K4退场标准。

### #2：长期安全性黑天鹅（概率15-20%）

**描述**：数百万用户长期使用后，此前临床实验无法检测的罕见副作用浮现（甲状腺C细胞肿瘤、胰腺炎进展为胰腺癌、胃轻瘫不可逆损伤、肌肉量流失致老年衰弱）。

**触发信号**：FDA发布Drug Safety Communication、大型真实世界研究显示长期风险显著升高、新增黑框警告

**传导路径**：高影响力期刊警示 → FDA修订标签 → 处方量断崖下跌 → LLY/NVO单日暴跌20-30% → 保险覆盖大幅收紧

**CIO评估**：GLP-1安全性数据基础远比Fen-Phen扎实（大规模CVOT+数年真实世界数据），但魔鬼辩护人的类比有警示意义。肌肉流失风险（25-40%减重来自瘦体重）对老年人群（Medicare Bridge目标用户）尤其值得关注。采纳K7退场标准。

### #3：仿制药+竞争者双重挤压致利润率崩溃（概率30-40%）

**描述**：semaglutide专利在关键市场2026年到期，仿制药以35-50%折扣涌入。5-10家竞争对手口服GLP-1在2027-2029密集获批。LLY/NVO收入增长但利润率大幅收缩。

**触发信号**：LLY/NVO毛利率连续两季度环比降>3pct（K5）；美国net price继续降30-50%；Amgen/Roche口服GLP-1 Phase 3数据积极

**CIO评估**：专利悬崖是确定事件。中国仿制药已上市（2折定价），美国仿制2028年进入。ICER数据显示竞争已推动净价下降50%。采纳PM建议：毛利率是定价权和竞争格局的终极指标。

## 六、辩论评级

**当前评级：有条件通过**（从"通过"下调）

**变动原因**：
1. **停药率数据**（关键因素）：魔鬼辩护人提出的50-81%停药率经A/C修订后确认，非T2D用户一年停药率65-75%，直接挑战"3000万活跃用户"和"终身用药"的核心叙事。H2假设被驳回。
2. **估值安全边际收窄**：LLY PEG从0.5x修正为1.0x（A修订），PE 38x在Higher for Longer环境下缺乏安全边际。
3. **正面因素确认**：LLY基本面无可争议（Q1 +56%、Retatrutide 28.3%、市占率60.1%），口服GLP-1需求真实（Wegovy口服2x预期、Foundayo快速爬坡），FDA 503B保护品牌定价。
4. **Medicare Bridge**：政策瓶颈部分突破但力度下修（首年100-200万而非200-400万）。

**维持"有条件通过"而非下调至"技术关注"的理由**：赛道方向正确（LLY基本面+口服需求+消费行为变化方向确认），核心风险（停药率）有趋势改善信号（33%→61%），NVO PE 10x提供安全边际。需在下次复查中确认口服留存率数据。
