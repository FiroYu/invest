# 研究员A：基本面分析（2026.06.04）

> 聚焦铀供需、核电运营商财务、投资标的估值

---

## 1. 铀价与供需

### 价格现状
| 指标 | 数值 | 变化 |
|------|------|------|
| 现货价（2026.06.02） | $86.25/磅 | 月跌0.23%，年涨19.96% |
| 长期合同价（Q1 2026） | ~$90/磅 | 2008年以来最高（ANS确认） |
| Q1 2026开盘价 | ~$80/磅 | 上半年涨幅~7.8% |

**重要修正**：上期报告长期合同价~$150/磅，现修正为$90/磅。此前的$150数据可能来自特定高端合同或经纪商报价。UxC和TradeTech的行业标准长期价格指标目前在$90附近，仍是2008年以来最高水平。现货/长期价差从上期$64大幅收窄至~$4，表明市场正通过现货上行实现价格收敛——这是看涨信号。

### 供给端
- **Kazatomprom减产确认**：2026年产量从~8500万磅下调至~7700万磅（-10%），移除约680万磅全球供应。明确表示"不计划恢复满产"
- **Cameco Key Lake临时停产**（2026年5月）：生产中断事件增加供给不确定性
- **俄罗斯铀进口禁令**：美国对俄铀进口限制持续，供应链碎片化加剧
- **Cameco 2026产量指引**：1950-2150万磅（自有份额），全年指引未变更

### 需求端
- **WNA预测铀需求2030年前增长28%**（从~170M磅/年→~210M磅/年）
- **全球437座运行反应堆**（~394 GWe），63座在建（~70 GW）
- **2026年将出现铀矿供给下降+反应堆需求上升的双向挤压**→确定性年度赤字
- 美国/中国/法国占全球铀需求~58%

### 供需结论
**结构性赤字确认**。Kazatomprom主动减产+俄铀禁运+在建反应堆投运 = 2026年铀市场确定性年度赤字。这是支撑铀价上行的最强基本面信号。

## 2. 核心标的基本面

### Cameco (CCJ)
| 指标 | 数据 |
|------|------|
| Q1 2026 EPS | $0.3377（超预期30%，预估$0.26） |
| 2026产量指引 | 1950-2150万磅U3O8 |
| 燃料服务指引 | 1300-1400万kgU |
| 分析师共识 | 买入（6位分析师） |
| 2026目标价 | $131.70 |
| 年度盈利增长预期 | 26.5% |
| 下期财报 | 2026.07.30（预估EPS $0.36） |
| 风险 | Key Lake临时停产（2026.05） |

**判断**：基本面持续走强。Q1超预期30%反映定价权和需求强度。Key Lake停产是短期风险但未改变全年指引。长期看，Cameco作为西方最大上市铀矿商，是铀结构性赤字的直接受益者。

### NexGen Energy (NXE)
- **Rook I项目（Arrow矿床）获最终联邦建设批准**（2026.03.05-06）
- 加拿大最大开发阶段铀项目
- 预计年产2540万磅U3O8，矿寿命9年
- 100%位于Athabasca盆地（世界最高品位铀矿区）
- **意义**：这是铀矿供给端最重要的新增产能，投产后将是Cameco的竞争对手，但中期（2028+）利好整个铀矿板块

### Constellation Energy (CEG)
| 指标 | 数据 |
|------|------|
| Q1 2026 EPS | $2.74（+28% YoY） |
| 股价 | ~$287.75 |
| P/E | ~25x（板块溢价25%） |
| 分析师评级 | Hold（当前）/ 审慎 |
| FERC裁决 | 2026年6-7月（关键催化剂） |
| 三里岛重启 | FERC已批准加速豁免，目标2028 |

**判断**：基本面强劲但估值已反映部分预期。FERC 6-7月裁决是股价方向的关键决定因素。通过CIR转移和容量互联权后，三里岛/Microsoft交易将进入执行阶段。

### Vistra Energy (VST)
- 19位分析师中16位"强烈买入"
- 平均目标价$243
- 2025年获得Fitch投资级评级
- 核电+数据中心PPA合同管道持续增长

### 核能板块ETF
- **URA（Global X铀ETF）**：直接铀敞口
- **NLR（核能ETF）**：分散核电运营商敞口
- **板块表现**：2026年初核能股暴涨35%+（NNE/SMR/OKLO），但近一个月回调~8.67%

## 3. 中国核电

| 指标 | 数据 |
|------|------|
| 运行机组 | 60座 / ~57-63 GW |
| 在建机组 | 36座（世界最大建设计划） |
| 15th Five-Year Plan目标 | 持续大幅扩核 |
| 同步建设能力 | 40+台机组 |
| 2030年目标 | ~110 GW |
| 2026政策 | 发改委"核电直连算力设施" |

**判断**：中国核电装机增长是全球核能复兴中确定性最高的变量。36台在建+40台同步建设能力 = 2030年110GW目标可达成。中国核电(601985)和中广核电力(01816.HK)是直接受益标的。
