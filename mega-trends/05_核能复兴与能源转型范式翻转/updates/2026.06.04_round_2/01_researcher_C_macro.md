# 研究员C：宏观分析（2026.06.04）

> 聚焦全球核能政策、能源安全、碳排角色、地缘政治、增强型地热威胁

---

## 1. 全球核能政策格局

### 多边框架
| 框架 | 进展 | 签署国 |
|------|------|--------|
| COP28三倍核能宣言（2023） | 首次将核能纳入COP议程 | 22国 |
| COP29扩展（2024） | 6国新加入 | 28+国 |
| COP30展望（2025） | 政治意愿强但执行/融资滞后 | 扩大中 |

**COP进程评估**：核能已从COP边缘议题转变为气候解决方案的"基石"（Harvard Belfer Center评价）。但CATF指出"实施和融资落后于政治意愿"——这是一个从宣言到行动的转化期。

### 主要国家/地区政策

| 国家/地区 | 政策方向 | 关键数据 |
|-----------|----------|----------|
| 美国 | 两党共识，加速审批 | Biden $9亿SMR + Trump核能复兴；NRC被要求压缩审批12-24月；200GW新核能目标 |
| 中国 | 最大建设计划 | 60座运行/36座在建；2030年110GW；"核电直连算力"政策 |
| 英国 | 积极扩核 | Sizewell C最终投资决定（2025）；核能峰会确认核心地位 |
| 法国 | 核能支柱 | ~70%电力来自核电；法德成立核威慑指导小组 |
| 加拿大 | SMR领先 | Darlington BWRX-300施工中；联邦政府已批准 |
| 德国 | 反核立场维持 | 2023年关闭最后一座；但欧洲能源安全讨论中核电地位上升 |

### 美国政策深度分析

**两党核能共识是2026年最重要的政策变量**：
- 民主党侧：Biden时代$9亿SMR投资、IRA核能税收抵免
- 共和党侧：Trump要求NRC加速审批、放松监管
- 印第安纳州首创20%核能制造税收抵免
- 纽约承诺新增5GW核电
- NRC十年首次发放商业堆建设许可（TerraPower）

**评估**：核能是美国极少数获得两党全力支持的产业政策领域。这种共识在当前政治极化环境下极为罕见，也是核能复兴政策确定性的最高保障。

## 2. 能源安全与地缘政治

### 铀供应链地缘风险
| 风险 | 影响 | 状态 |
|------|------|------|
| 俄铀进口禁令 | 切断~20%美国铀供应来源 | 已实施 |
| 哈萨克斯坦减产 | 移除全球~5%初级供应 | 已确认 |
| 中亚地缘不稳定 | 铀运输通道风险 | 持续 |
| 中国铀储备战略 | 可能加剧供给紧张 | 长期 |

**评估**：铀供应链集中度极高——哈萨克斯坦(~42%)、加拿大(~15%)、纳米比亚(~10%)、澳大利亚(~8%)。地缘政治正在将铀从大宗商品转变为战略资源。这对西方铀矿商（Cameco、NexGen）是结构性利好。

### 能源安全视角
- **俄乌战争教训**：欧洲能源危机（2021-2022）证明过度依赖单一来源的风险 → 核能作为"主权能源"的价值被重新认识
- **AI电力安全**：AI数据中心需要7x24基荷电力 → 核能是不可替代的电力安全锚
- **中国核电自主**：中国拥有完整的核燃料循环能力，核能是其能源自主战略的核心

## 3. 碳中和与核能角色

### 核能的碳排贡献
- 当前避免排放：**1.5 Gt CO2/年**（IEA）
- 全球核电装机：413 GW / 32国
- 核能是唯一能提供7x24零碳基荷电力的技术

### 核能vs可再生能源的系统性对比
| 维度 | 核能 | 可再生（风/光） |
|------|------|-----------------|
| 间歇性 | 无（基荷） | 有（需要储能） |
| 土地密度 | 高（小面积大功率） | 低（大面积低功率） |
| 全生命周期碳排 | ~12g CO2/kWh | ~20-50g CO2/kWh |
| 建设周期 | 7-15年（传统）/3-5年（SMR目标） | 1-3年 |
| LCOE | $60-130/MWh（新建设） | $30-60/MWh |
| 储能成本 | 不需要 | 需要额外$50-150/MWh（电池） |

**关键洞察**：当把储能成本计入后，核能在7x24基荷场景下的实际成本竞争力大幅提升。AI数据中心需要的正是7x24基荷电力——这不是核能vs可再来的选择题，而是核能不可替代。

## 4. 横向风险因子分析

### 因子1：AI CapEx超级周期 — 高敏感
**当前状态**：$700B Hyperscaler CapEx确认（+40% YoY）
**影响路径**：AI CapEx → 数据中心电力需求 → 核电PPA签约 → 铀需求预期
**风险**：若2026H2 Hyperscaler开始削减CapEx指引，核电PPA需求将承压
**缓冲**：已签约PPA（10+ GW）具有长期合同保护，短期CapEx波动不直接影响

### 因子2：利率Higher for Longer — 高敏感
**当前状态**：10Y ~4.3%，降息预期推迟
**影响路径**：高利率 → 核电/SMR项目融资成本上升 → 项目IRR下降 → 建设决策推迟
**风险**：SMR项目首台成本已高（BWRX-300 ~$61亿加元/台），高利率进一步侵蚀经济性
**缓冲**：科技公司直接投资/PPA预付部分替代了传统项目融资

### 因子3：中美脱钩 — 中敏感
**当前状态**：阶段性缓和（Trump访华、$300亿关税削减框架）
**影响路径**：技术管制 → 核电技术竞争 → 铀供应链碎片化
**风险**：核能是中美竞争的关键技术领域，全面技术封锁将影响SMR技术传播
**缓冲**：核能建设以国家主导为主，中美脱钩对各自核能建设节奏影响有限

### 因子4：私募流动性 — 低敏感
核能板块以大型上市公司为主（CEG、CCJ、VST），私募敞口有限。

## 5. 增强型地热(EGS) — 核能基荷的潜在颠覆者

### Fervo Energy进展
| 指标 | 数据 |
|------|------|
| 商业规模EGS发电 | 2024年犹他州3.5MW |
| 400MW Utah项目 | 建设中 |
| Google合作 | $4.21亿合同 |
| 总签约合同 | $68亿 |
| IPO预期 | 2026-2027 |
| EGS潜在角色 | 可供应数据中心~2/3新增电力需求（Rhodium Group） |
| 成本趋势 | 降至$20/MWh |

### EGS vs 核能对比
| 维度 | EGS | 核能 |
|------|-----|------|
| 7x24基荷 | 是 | 是 |
| 部署速度 | 更快（可能在2030前） | 更慢（SMR 2027-2030） |
| 燃料需求 | 无（地热） | 需要铀矿 |
| 选址限制 | 有（需要合适地质） | 有（需要冷却水源等） |
| 规模 | 单项目~400MW | 单堆10-345MW但可组合 |
| 监管复杂度 | 低 | 极高（NRC） |
| 技术成熟度 | 商业验证中 | 成熟（传统）/验证中（SMR） |

**宏观评估**：EGS不是核能的替代品，而是互补品。Google同时签约Fervo（地热）和Kairos（SMR），说明科技巨头在基荷电力上采取"all of the above"策略。EGS对核能的最大威胁不在技术层面，而在投资资金分流——如果EGS IPO表现强劲，可能分流部分核能投资。

---

## 6. 宏观结论

| 维度 | 判断 | 信心度 |
|------|------|--------|
| 全球核能政策方向 | 强正向（三倍宣言+两党共识+COP连续三年） | 高 |
| 铀供应链安全 | 结构性趋紧（俄禁运+哈减产+新需求） | 高 |
| AI电力需求确定性 | 高（700B CapEx+10GW已签约） | 高 |
| 利率对核能影响 | 负面但可控（科技公司直接投资缓冲） | 中 |
| EGS威胁 | 有限（互补而非替代） | 中 |
| 核能碳中和角色 | 不可替代（唯一7x24零碳基荷） | 高 |
