# 议题10：自动驾驶L4L5与交通运输价值链重构

> ## Round 3 综合裁定（2026.07.10，CIO 综合）
> **评级**：**积极关注·事件驱动跟踪档**（维持 + 分层升级；**不上调**至核心配置/超配）
> **一句话判断**：2026 商业化拐点已从"预期"进入"数据验证"阶段——Waymo 周单 50 万（口径从"累计"修正）+ Aurora 运力售罄 + 中国 NOA 渗透 56.6% 三组硬证据；但 Waymo $126B 估值（~348x P/S）已 price-in 拐点预期、Tesla NHTSA PE24031 调查未结、Cruise $100 亿退场警示资本周期——价值创造分化为三条确定性截然不同的赛道，投资框架从"行业 beta"转向"三层分化 alpha"。
> **R2→R3 关键变化**：Waymo 50 万口径修正（累计→周单）/ Cruise 移出标的池（GM 退场）/ Tesla 无监督 FSD 跳票 Q4 2026 / 端到端"待验证"→"行业共识"(H4 85%) / 三法域监管走向"成文法"但 bill≠law (H3 68%)。
> **完整裁定**：[`updates/2026.07.10_round_3/_synthesis.md`](updates/2026.07.10_round_3/_synthesis.md)

## 核心判断（R2 基线，05.25）

2026年是自动驾驶出行商业化拐点年。Waymo在10个城市部署3700+辆车，已提供约50万次付费出行，证明Robotaxi模式可规模化。Aurora的无人卡车在德州实现24/7不间断商业运营，将自动驾驶最直接的商业价值——替代长途卡车司机——变为现实。法律责任正在从个人驾驶员系统性转移向制造商，Morningstar预测个人汽车保险可能在20年内过时。这一转变不仅影响汽车行业，将重塑保险、物流、城市规划和能源基础设施。

## 关注模型

- **Robotaxi单量/覆盖城市增速**：衡量商业化的核心速度指标。Waymo每季度新增城市数和单量增长率直接反映扩展节奏。
- **自动驾驶卡车运营里程**：Aurora、Kodiak等公司的月度运营里程是B2B场景商业化的硬指标。
- **个人汽车保险费率变化**：当保险公司开始基于自动驾驶数据调整费率模型时，标志着责任转移进入实质性阶段。
- **Uber/Lyft司机收入趋势**：司机供给和收入的变化是Robotaxi替代效应的滞后指标，但方向性意义重大。

## 投资含义（R3 更新）

- **维持「积极关注」升级为「事件驱动跟踪档」**——拐点已被硬数据确认（H1 82%），但 Waymo 348x P/S 已 price-in、Tesla NHTSA 未结、Cruise 退场警示，**在估值扩张完成后不追多**
- **配置框架从"行业 beta"转向"三层分化 alpha"**（目标权重 8-10%）：
  - **确定性层 55%**：MBLY 15%（ADAS 卖水人，不依赖 L4）/ GOOGL 15%（Waymo 期权）/ AUR 12%（B2B 卡车最确定，分两批）/ 9666.HK 8%（中国 NOA 国产替代）/ HSAI 5%（激光雷达，地缘触发条）
  - **高 beta 层 30%**：BIDU 10%（Apollo Go 出海）/ UBER 8%（聚合层轻资产）/ AMZN 5%（Zoox 期权）/ TSLA 7%（**暂不建仓**，待 Q2 财报+NHTSA）
  - **投机对冲层 15%**：**WRD 空头 5%**（行业证伪 asymmetric hedge）/ PONY 4%（弹性观察）/ 现金 6%
- **关键裁定**：Waymo $126B **不作正面证据**（348x P/S 是上行约束）；Aurora 认可技术验证但不以 $80M run rate 给权重（$3M 实收）；百度盈亏平衡标注"中国特定条件"
- **NVIDIA 不在 #10 单独配**——已由 #01/#17 覆盖（PM 去重）

## 最新更新 — 2026.07.10（Round 3 CIO 综合）

### 评级：维持「积极关注」→「事件驱动跟踪档」（分层升级，不上调）

拐点从预期→数据验证（H1 82%）；但 Waymo 348x P/S price-in + Tesla NHTSA + Cruise 退场 → 不超配。需 Q3-Q4 验证窗口确认后才能上修（T8/T9）。

### 头号裁定：拐点确认但价值创造分化为三条赛道

| 赛道 | 确定性 | 代表标的 |
|------|--------|---------|
| ① B2B 无人卡车 | ★★★★★ 最高 | Aurora (AUR) |
| ② ADAS/NOA 卖水人 | ★★★★☆ 高 | Mobileye (MBLY) / 地平线 (9666.HK) |
| ③ 城市 Robotaxi | ★★★☆☆ 分化 | Waymo(GOOGL) / Baidu(BIDU) / Tesla(TSLA) |

不再购买"自动驾驶行业 beta"，而是分层选择确定性最高的 alpha。

### 情景概率 A/B/C/D

| 情景 | 概率 | 描述 |
|------|------|------|
| A 全面加速 | **28%** | Waymo 年底周单>70 万 + 联邦 AV 法签署 + 无监管回退 |
| **B 主线（分化加速）** | **42%** | 商业化继续但分化加剧；监管渐进式落地 |
| C 重大事故/监管回退 | 20% | L4 致死事故 / NHTSA 召回 Tesla / 百度二次故障 |
| D 资本寒冬/地缘脱钩 | 10% | Pony/WeRide 出清 + 中美 AV 硬脱钩 |

**A+B = 70% 积极主导；C+D = 30% 显著放缓** → 决定"积极关注但不超配"基调。

### H1-H5 信心度（节选）

- **H4 端到端/世界模型**：**85%**（R2 55% → +30pp，最大上修——从"待验证"到"行业共识"）
- **H3 三法域监管走向成文法**：**68%**（R2 50% → +18pp，方向确认但 bill≠law）
- H1 商业化拐点：82%（+12pp）；H2 无人卡车先盈利：75%（+15pp）

### 三层组合配置（目标 8-10%）

确定性 55%（MBLY/GOOGL/AUR/9666/HSAI）+ 高 beta 30%（BIDU/UBER/AMZN/TSLA 暂不建）+ 投机对冲 15%（WRD 空头 5% + PONY 4% + 现金 6%）。规则：单一标的≤20%、纯 Robotaxi≤20%、中国汇总≤35%。

### 与 R2 最关键的 3 个 diff

1. **Waymo 50 万口径修正**（累计→周单）+ $126B 估值锚定——商业化速度被低估但估值已 price-in
2. **Cruise 移出标的池**（GM $100 亿退场 = R2 前提失效）+ Tesla FSD 跳票 Q4 2026 + NHTSA PE24031 安全调查——标的池收缩与安全风险是 R2 未充分定价的新风险
3. **端到端"待验证"→"行业共识"**(H4 85%) + 三法域监管"成文法"方向(H3 68%)

### 头号风险：Tesla NHTSA 升级触发监管寒冬（概率 ~25%）

对冲：WRD 空头 5%（行业证伪 asymmetric hedge）+ TSLA 暂不建多头 + 确定性层偏重"卖水人"（MBLY 不依赖 L4 监管）+ AUR 作为 B2B 场景对冲。

### 跨议题传导

- **#01 AI CapEx ↔ #10**（双向锁定，最强耦合）：AV 是 NVIDIA 继云厂商后第二大买家；若 #01 进入 CapEx 回报质疑期，AV 真实营收（Aurora $80M / Waymo 周单 50 万）成为 AI CapEx 周期的"价值锚"
