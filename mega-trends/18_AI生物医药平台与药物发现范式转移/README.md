# 议题18：AI生物医药平台与药物发现范式转移

> Round 3 更新（2026-07-10）：评级维持「积极关注」，但显式分化；Recursion 单独降级为「事件驱动观察」。R2 英矽代码错误 ISOL 已修正为 03696.HK。

## 核心判断

AI 药物发现已经从「概念验证」进入「分化验证期」。Rentosertib（INS018_055）Phase III 启动与 REC-4881 Phase 2 PoC 证明 AI 能设计出进入人体并显示疗效的分子，这是范式锚；但价值创造方向与 R2 的「独立平台颠覆 Big Pharma」设想不同。OpenAI、Google、NVIDIA 与大型药企直接下场，正在把生物 AI 能力内化，独立平台公司的授权溢价被结构性压低。端到端成本节约也从 R2 隐含的 50%+ 修正为 15-25%。

## 关键指标

| 指标 | 数据 |
|------|------|
| R3 评级 | 积极关注（维持）+ 显式分化；Recursion 事件驱动观察 |
| 范式锚 | Rentosertib Phase III；REC-4881 Phase 2 PoC |
| 成本节约修正 | 发现端降 30-40%；端到端实际节约 15-25% |
| 临床成功率 | Phase I 80-90% 含选择偏差；Phase II 约 40%，尚未显著优于历史 |
| 巨头下场 | OpenAI/Novo、Google Isomorphic、NVIDIA BioNeMo 直接进入生物 AI |
| 独立平台风险 | Big Pharma 倾向自建、入股和平台级绑定，授权天花板下修 |
| Recursion | 市值约 $2.1B；Q1 2026 营收大幅 miss，单独降级观察 |
| 晶泰科技 | 2228.HK；服务模式盈利验证，药物发现收入高增 |
| 英矽智能 | 03696.HK；Rentosertib 是范式锚，高 beta 层 |

## 关注模型

- **Rentosertib Phase III**：2027 中期数据是范式定调事件；失败会重创高 beta 层
- **REC-4881 注册路径**：FDA 若要求完整 Phase 3，Recursion 继续观察；若出现加速路径，投机层可重估
- **巨头商业化里程碑**：OpenAI/Google/NVIDIA 生物 AI 平台若直接产出商业分子，独立平台估值继续承压
- **临床 AI 层增速**：Tempus 是否维持 +30% 以上增长，对应真正临床瓶颈
- **服务模式验证**：晶泰/Schrödinger 是否能通过服务费、软件订阅和合作里程碑独立造血
- **大药企 AI 合作结构**：首付款占总额比例、合作是否从外采转向内建，是判断平台议价能力的关键
