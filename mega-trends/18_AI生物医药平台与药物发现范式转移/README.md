# 议题18：AI生物医药平台与药物发现范式转移

> Round 4 更新（2026-10-10，目录 2026.09.03_round_4）：评级维持「积极关注+显式分化」，框架从"分子验证驱动"切换为"**资本定标驱动**"——Isomorphic $40-50B 融资谈判（H3 极端强化）；五标的财务三分化（英矽首次中报盈利 +287%/晶泰转亏/RXRX 再 miss）；**E4 口径成文：授权费驱动的盈利≠商业模式验证（晶泰教训）**；12M 加权 +3.6%。

## 核心判断

**本窗口无范式级临床事件，但有范式级资本事件。** Rentosertib III 期（GENESIS-IPF-3）9/10 完成中国首例给药——执行正常，读出在 2027 中；REC-4881 的 FDA 注册路径悬置至 11 月遗传性 GI 年会。与此同时，**Isomorphic Labs（Google/DeepMind 系，无公开命名的临床候选物）传出 $40-50B 估值融资谈判**——距 $2.1B Series B 仅 5 个月，与公开市场同业（RXRX ~$2B/英矽 ~$2-3B/SDGR ~$1.2B）形成 20-40 倍裂口。H3（巨头下场）从"合作预算竞争"升级为"估值定价权竞争"（75%→80%）——**对公开独立平台净效应偏负，对 GOOGL/LLY 隐含期权为正**。

**五标的财务三分化（R3"显式分化"判断的数据化验证）**：英矽 H1 营收 $106.3M（+287%）+首次中报盈利；晶泰 H1 转亏（-23.9%，剔除基数 +73.8%）；RXRX Q2 营收 $7.67M（-60%）再 miss；Tempus +22% 踩 T7 线（+25%）；Schrödinger ACV +27% 加速+Bunsen 发布。

**方法论修正（E4 成文）**：R3 采纳的"晶泰服务模式盈利验证"13 周内被 H1 转亏证伪——**授权费/里程碑驱动的盈利自此不构成"商业模式验证"论据**；只有经常性收入（订阅/服务费/royalty）可作验证口径。英矽盈利记"事实+波动性警示"；REC-4881 的"AI 设计"标签祛魅（in-licensed Takeda 2006 老分子，范式锚收窄至 Rentosertib 单样本）。

## 关注模型

- **REC-4881（11 月 GI 年会+FDA 路径）**：加速批准 → T2' 反向条款（RXRX 0→1%）；完整 Phase 3 → T2（维持 0%）
- **Isomorphic 融资关闭**：<$25B 或破裂 → E1（英矼减半+巨头锚重审）
- **Rentosertib**：全球入组进度（2027 中读出=范式终审，H4 55%）
- **TEM Q3**：再 <+25% → T7 执行（TEM→SDGR/晶泰再平衡）
- **英矼 H2 营收**：< $30M → E2（回纯 III 期期权定价）
