## 一句话判断（R2 基线，05.25）
> 这不是"可能发生"的范式转移，而是**正在发生**。铜互连在 200G/lane 以上触及物理极限（信号2米内衰减），光替代铜从数据中心机架向芯片内部推进，2026年是CPO（共封装光学）量产元年。光子计算（用光而非电做计算）也已从实验室走向商业化。整条价值链从材料、芯片、封装到系统都在被重塑。

## 为什么重要

- **人类影响**：AI算力增长的最大瓶颈已从"计算"转向"数据搬运"（互联）。光学互联是突破这一瓶颈的唯一物理路径，直接决定AGI何时到来
- **经济影响**：硅光子市场 2025年~$2.9B → 2030年~$9.7B（CAGR 29.5%）；CPO市场 2024年$46M → 2030年$8.1B（CAGR 137%）。中国厂商主导全球光模块市场（70%+份额），是少数中国具有全球定价权的科技领域
- **时间敏感度**：2026年是关键拐点——台积电硅光子迈向量产，NVIDIA开始CPO量产，1.6T光模块开始部署。2027-2028年渗透率加速

## 范式转移的三个层次

本议题涵盖三条互相交织但节奏不同的技术路线：

### 层次一：光刻技术演进（芯片制造）
- **本质**：从 EUV 到 High-NA EUV，是连续演进而非范式转移
- **关键玩家**：ASML（垄断）、ZEISS（光学系统）
- **时间线**：High-NA EUV 2026年量产后用于 sub-2nm 制程
- **判断**：延续性创新，不构成结构性价值链重塑

### 层次二：光学互联替代铜（芯片互联）★ 核心范式转移
- **本质**：铜互连 → 光互连，从机架级向芯片级推进
- **演进路径**：可插拔光模块 → CPO（共封装光学）→ Optical I/O（芯片间光互连）→ 片上光互连
- **驱动力**：AI训练集群规模爆炸（十万卡+），铜缆在200G/lane以上物理失效
- **时间线**：2026年CPO量产元年，2028-2030年CPO渗透率达35%

### 层次三：光子计算（用光做计算）
- **本质**：用电做矩阵运算 → 用光做矩阵运算，潜在的终极范式转移
- **进展**：Lightmatter 2025年在Nature发表论文验证光子AI加速器
- **时间线**：商业化早期阶段（2025-2028），大规模应用需更长时间
- **判断**：高潜力但不确定性大，值得跟踪但尚非投资主线

## 核心争议点

### 正方（光替代铜已成必然）
- 铜在 200G/lane 时信号仅能传输 ~2 米，AI训练集群需要万卡互联，铜已无法胜任
- NVIDIA/AMD/Intel 三巨头联合投资 Ayar Labs，产业共识已形成
- 2026年台积电硅光子量产，CPO从概念走向产品
- 中国政策明确支持（工信部《电子信息制造业2025-2026年稳增长行动方案》）

### 反方（铜仍在反击）
- AEC（有源电缆）和 CPC（共封装铜）技术在延长铜的寿命
- CPO 的封装良率和热管理仍是挑战
- 可插拔光模块生态成熟，短期内性价比仍优于 CPO
- 光子计算的大规模商业化尚需时日

### 当前共识
- 机架间光互连已是定局（已全面光子化）
- 芯片间光互连（CPO/Optical I/O）是下一个确定性方向
- 片上光计算是远景方向，短期投资价值有限

## 最新更新 — 2026.07.10（Round 3 CIO 综合）

### 评级：有条件通过（从「积极关注/技术关注」升级）

光学互联的范式转移已从「正在发生」变为「已被验证」。CPO 量产不再是 PPT，硅光占比 2026 首次突破 50%（触发 README 判断阈值），NVIDIA $40 亿垂直整合 Lumentum+Coherent。**维持「积极关注」将低估已确认的范式转移**——因此升级。但条件极其严格。

### 六大事实裁定

1. **CPO 量产已兑现（触发升级）**：NVIDIA Spectrum-X Photonics（full production）+ Quantum-X（115.2Tbps）+ Broadcom Bailly（量产、故障率极低）+ TSMC COUPE（2026 CoWoS 集成量产）。客户确认 TACC/Lambda/CoreWeave。**量产是事实不是预期**
2. **TAM 下修矛盾**：7/8 独立机构 2030 CPO 预测 $0.8-3.4B（vs 基线 $8.1B）。**技术验证 ≠ 渗透节奏——方向对、节奏慢 2-3 年**。下修基线 TAM 至 $2-3B@2030（CAGR 70-90%）
3. **估值不阻碍升级但约束仓位**：中际旭创远期 PE 40-44x 在 +175% 增速下可辩护（PEG <0.3），但 TTM P/E 82-95x + 溢价 +111% + 库存 +105% = 容错率极低。**评级=方向判断，仓位=风险管理**
4. **High-NA 降权（层次一证伪）**：TSMC A14/A13/A12 全不用 High-NA（Reuters 确认），仅 Intel 14A（2027）采用且保留切回权利。客户池从「所有先进制程」收窄至 Intel+Samsung+Rapidus
5. **铜反击真实但局部**：224G CPC 已商用（Molex/Amphenol），448G 开发中。Scale-Out/机架间已全面光子化不可逆；Scale-Up/封装内 <2m 铜仍有 2-3 代竞争力。CPO 大规模渗透推迟到 102.4T 之后（2028+）
6. **光子计算维持「跟踪不投资」**：Ayar Labs $37.5 亿 + Lightmatter $44 亿 + 曦智 800 亿港元市值（P/S ~750x），**三者合计大客户商用营收 = 0**。资本驱动 ≠ 商业拐点

### 升级条件（需全部满足，违反任一则降回「积极关注」）

- **C1**：仅限层次二（光学互联）主线；层次一降权，层次三「跟踪不投资」
- **C2**：仓位分层——确定性 60-70% + 高 beta 20-30% + 投机 <10%
- **C3**：禁止追高 TTM P/E >100x 二线标的（天孚 138x / 东山 211x / 曦智 P/S 750x）
- **C4**：5 条收紧触发（T1-T5）持续监控
- **C5**：每 6 周复查（下次 2026.08 下旬，含 Q2 财报验证）
