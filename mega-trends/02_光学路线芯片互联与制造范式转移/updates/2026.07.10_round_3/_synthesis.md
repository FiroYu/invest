# CIO 综合裁定 — 课题 #02 光学路线芯片互联与制造范式转移（Round 3）

> CIO 最终裁定 | 2026-07-10 | 基于 R2 基线（README）+ 3 份研究员报告（A 基本面 / B 催化 / C 宏观）+ 魔鬼辩护人 + PM 审查
> **本轮头号裁定**：升级至「有条件通过」——CPO 量产元年已从「预期」变为「事实」（NVIDIA/Broadcom/TSMC 三重验证），硅光占比 2026 突破 50%（触发 README 判断阈值），方向不可逆性增强。但条件极其严格：仅限层次二光学互联主线 + 确定性层仓位 + 5 条收紧触发。层次一（High-NA EUV）降权（TSMC 拒绝），层次三（光子计算）维持「跟踪不投资」（商用 = 0）。估值泡沫区（TTM P/E 82-95x）通过分层仓位管理而非拒绝升级来应对。

## 一、本轮头号裁定（一段话）

**光学互联的范式转移已从「正在发生」变为「已被验证」**：CPO 量产不再是 PPT（NVIDIA Spectrum-X/Quantum-X 出货、Broadcom Bailly 故障率极低、TSMC COUPE 量产），硅光调制器占光模块销售首次 >50%（触发 README「硅光路线胜出」阈值），1.6T 正式起量（中际旭创 50-70% 份额），NVIDIA $40 亿垂直整合 Lumentum+Coherent（GPU 巨头用真金白银声明光的战略地位）。**方向不可逆性确认，升级至「有条件通过」。** 但 TAM 预测被 7/8 独立机构下修 58-91%（$8.1B→$2-3B@2030），估值进入历史 80-90 分位（中际旭创 TTM P/E 82-95x、溢价 +111%），库存 +105%、光子计算商用 = 0、铜 224G CPC 已商用（README「铜无法突破 224G」阈值未触发）。**因此升级条件严格：仅限层次二主线，仓位分层管理，5 条收紧触发，8 月初 Hyperscaler Q2 财报为共同裁定窗口。**

## 四、评级

### 评级：有条件通过（从 R2 隐含「积极关注 / 技术关注」升级）

### 评级裁定的核心逻辑

**技术拐点已被多重验证，方向不可逆性增强。README 明确设定的判断阈值已触发。维持「积极关注」将低估已确认的范式转移——CPO 量产不是预期而是事实，硅光 >50% 不是趋势而是转型。**

但升级条件严格，因为：
1. TAM 下修 63-75%（方向对、节奏慢）
2. 估值进入历史极端（TTM P/E 82-95x、溢价 +111%）
3. 库存 +105% + 产能释放（周期顶部信号）
4. 铜反击已商用（CPO 渗透推迟 2-3 年）
5. AI CapEx 债务融资阶段（#01 共同生死门）

**因此升级 = 「方向确认 + 仓位约束」，不是「无脑追高」。**

### 升级条件（需全部满足，违反任一则降回「积极关注」）

| 条件 | 内容 | 当前状态 |
|------|------|---------|
| **C1** | 仅限层次二（光学互联）主线。层次一（High-NA）降权，层次三（光子计算）「跟踪不投资」 | 满足 |
| **C2** | 仓位分层：确定性 60-70% + 高 beta 20-30% + 投机 <10% | 待执行 |
| **C3** | 禁止追高 TTM P/E >100x 的二线标的（天孚/东山/曦智） | 待执行 |
| **C4** | 5 条收紧触发（T1-T5）持续监控 | 设定中 |
| **C5** | 每 6 周复查（下次 2026.08 下旬，含 Q2 财报验证） | 承诺 |

## 十二、CIO 核心裁定依据

### 裁定 1：为何升级至「有条件通过」而非维持「积极关注」

**三重验证已使方向判断从「大概率」升至「基本确定」：**

1. **CPO 量产已兑现**（NVIDIA Spectrum-X/Quantum-X 出货 + Broadcom Bailly 量产 + TSMC COUPE 量产）——这不是预期而是事实。README「2026 = CPO 量产元年」判断已验证
2. **硅光占比 2026 >50%**——直接触发 README「硅光路线胜出」阈值
3. **NVIDIA $40 亿垂直整合 Lumentum+Coherent**——GPU 巨头用真金白银声明光的战略地位

**维持「积极关注」将低估已确认的范式转移。** C 宏观研究员的「不升级」建议在方向判断上过于保守——技术拐点已被多重独立验证，这不是「可能发生」而是「已经发生」。

### 裁定 2：为何条件严格而非无条件通过

**C 宏观 + 魔鬼辩护人在估值/风险上的判断优于 A/B：**

1. TAM 下修 63-75%（7/8 源支持）→ 渗透节奏比基线慢 2-3 年
2. 估值 TTM P/E 82-95x + 溢价 +111% → 已 price-in 2027 盈利
3. 库存 +105% + 产能释放 → 周期顶部信号
4. High-NA 被 TSMC 拒绝 → 层次一逻辑证伪
5. 光子计算商用 = 0 → 资本驱动非业务驱动
6. AI CapEx 债务融资 → #01 共同生死门

**因此升级 = 「方向确认」+「仓位约束」。评级反映方向确定性（上调），仓位反映风险不确定性（分层 + 触发）。**

### 裁定 3：TAM 下修矛盾的解释

**量产已兑现但 TAM 下修不是矛盾——是「技术验证」与「商业渗透节奏」的时间差。** CPO 技术路线已被证明可行（不再是 if），但渗透节奏因 LPO/XPO 生态惯性 + CPC 铜反击 + 良率/热管理障碍而比基线预期慢 2-3 年。TAM 从 $8.1B 下修到 $2-3B 反映的是节奏修正，不是方向否定。**CIO 下修基线 TAM 至 $2-3B@2030（CAGR 70-90%），而非 $8.1B。**

### 裁定 4：估值不阻碍升级但约束仓位

**评级是「方向判断」，仓位是「风险管理」。** 两者不可混淆。中际旭创远期 PE 40-44x 在 +175% 增速下可辩护（PEG <0.3），但 TTM P/E 82-95x + 溢价 +111% 意味着容错率极低。通过分层仓位（确定性 60-70%）+ 收紧触发（T1-T5）+ 禁止追高（C3）来管理估值风险，而非因估值高就拒绝承认技术拐点。

### 裁定 5：High-NA EUV 降权 + 光子计算维持跟踪

**层次一（High-NA）从「延续性创新」下调为「客户池显著窄化的高赌注」**——TSMC 拒绝意味着近期客户仅 Intel+Samsung+Rapidus。**层次三（光子计算）维持「跟踪不投资」**——三家公司合计 >$100 亿估值但商用 = 0。两者均不贡献升级理由。**升级仅基于层次二（光学互联）主线。**
