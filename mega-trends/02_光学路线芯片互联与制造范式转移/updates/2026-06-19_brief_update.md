# 光学路线芯片互联与制造范式转移 动态更新 2026-06-19

## 关键进展

1. **NVIDIA Spectrum-X CPO 交换机进入量产并开始出货** - 6月3日GTC Taipei上，NVIDIA宣布其下一代Spectrum-X共封装光学（CPO）以太网交换机进入全规模量产，并已开始向部分合作伙伴出货。该产品号称是首款达到此阶段的CPO交换机，单机吞吐达400 Tbps，能效提升5倍、可靠性提升10倍，将作为Vera Rubin AI工厂平台的scale-out/scale-across网络主干。这是CPO技术从"样品/原型"进入"规模化生产"的里程碑事件。（NVIDIA News / Studio Global / 多个来源, 6月3-4日）

2. **Aehr获大客户追加订单——光子片子级老化测试设备** - 6月17日，Aehr Test Systems宣布获得某"重要硅光子客户"的追加订单，采购用于超大规模数据中心光学互联的全自动片子级老化（wafer-level burn-in）系统FOX-CP。追加订单（follow-on order）直接验证了硅光器件正从研发验证走向批量制造，对光子/集成光学器件的测试产能需求正在释放。（Aehr, 6月17日）

3. **Ayar Labs加入NVIDIA NVLink Fusion生态** - 6月3-8日，Ayar Labs（已完成含NVIDIA参投的$5亿E轮）加入NVIDIA NVLink Fusion生态，将其CPO产品与NVIDIA光学/SerDes技术实现光电兼容，覆盖AI scale-up的chip-to-chip光学互联。CPO正从单一供应商路线扩展为NVIDIA主导的开放生态。（Semiconductor Today / Optical Connections, 6月3-8日）

## 影响评估

- **对光学互联赛道的影响**：上期（6.12）更新聚焦Marvell/Ayar Labs的资本事件，但遗漏了本赛道2026年最具决定性的事件——NVIDIA自家Spectrum-X CPO交换机量产出货。CPO首次进入规模化生产，标志着光学互联从"技术验证/资本炒作"跨入"AI工厂基础设施部署"阶段。Aehr的追加订单与Ayar Labs接入NVLink Fusion从测试设备端和生态端两侧交叉印证了量产 ramp 的真实性。
- **投资含义**：CPO量产使光学互联的可投资性显著提升。直接受益：NVIDIA（自研CPO网络）、Ayar Labs（私有，CPO scale-up）、Marvell（MRVL，ASIC+光学双栖，已纳入S&P 500）、Broadcom（AVGO）。测试设备端的Aehr（AEHR）是CPO量产的"卖水人"信号。需关注CPO对传统可插拔光模块厂商（如中际旭创/Coherent等）的替代压力。
