# 议题13：mRNA癌症疫苗与个性化医疗范式

> Round 3 更新（2026-07-10）：评级维持「积极关注」，催化密度由「中」上调至「高」。核心约束：INTerpath-001 Phase 3 读出前不追高 MRNA/BNTX 高 beta 仓位。

## 核心判断

mRNA 技术正在从"疫苗平台"进化为"可编程的药物开发操作系统"。COVID 疫情验证了 mRNA 平台的快速响应能力（从序列到临床仅 63 天），现在这一能力正在被指向癌症——人类最大的疾病负担。

**范式转变**：从"一药治百人"到"一人一方"。个性化 mRNA 癌症疫苗为每位患者的肿瘤新抗原（neoantigen）量身定制 mRNA 序列，教会免疫系统识别和攻击癌细胞。

**核心证据**：Moderna/Merck 的 mRNA-4157（V940 / intismeran）联合 Keytruda 用于黑色素瘤的 5 年随访数据显示：
- 复发/死亡风险降低 **49%**，RFS HR 0.51
- 无远处转移生存期显著延长，DMFS HR 0.41，5 年 DMFS 83.9%
- 已获 FDA 突破性疗法认定，INTerpath-001 Phase 3 已全部入组
- 期中分析预计 2026H2 读出，是全年决定性二元事件

如果 Phase 3 验证 Phase 2 结果，这将是**个性化 mRNA 癌症疫苗的历史性突破**。但 Phase 2b 样本量小、开放标签、OS 仍只是 improvement trend，CIO 对验证概率采用 55-65% 的保守区间；在数据读出前，评级不上调至「有条件通过」。

与此同时，mRNA 平台的应用边界持续扩展：罕见病蛋白质替代、自身免疫病、基因编辑递送、慢性给药。长期看，mRNA 仍有机会成为继小分子和抗体之后的**第三大药物模态**，但路径更可能从治疗性癌症疫苗突破，而非预防性疫苗线性外推。

初始建仓以 MRK/ILMN 为主；MRNA/BNTX 等回调或 Phase 3 读出后再提高权重。MRNA + BNTX 合计上限 4.0%。

## 关注模型

- **mRNA-4157 Phase 3 数据**：INTerpath-001 HR <0.5 触发加仓；HR 0.65-0.8 触发减仓；未达主要终点触发评级降级
- **Moderna/BioNTech 管线进展**：BNT122 是否在 2026 底/2027 初启动 Phase 3；Moderna 现金跑道是否维持
- **FDA 审批时间表**：突破性疗法认定可能加速但不确定
- **个性化医疗定价模式**：支付方是否接受高价个性化疗法
- **#18 AI 降本传导**：AI 新抗原预测、序列优化和制造工艺能否把个性化周期压至 2-3 周
- **竞争格局**：传统免疫疗法、细胞治疗（CAR-T）、其他新抗原疫苗
- **预防端风险**：mRNA-1010 PDUFA、CMV/流感线后续是否继续拖累平台叙事
