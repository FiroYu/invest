# 议题13：mRNA癌症疫苗与个性化医疗范式

> Round 4 更新（2026-10-10，目录 2026.09.03_round_4）：**评级上调「有条件通过」（T8 触发）**——INTerpath-001 Phase 3 双终点阳性（8/19）；条件=ESMO 10.24 HR 分档 + BLA 2027Q2 前递交。MRNA 高 beta 上限压至 1.0%（估值纪律，市值 ~$75.8B/超 PT 中位 51-80%）。

## 核心判断

**范式已确认，价格未确认。** 2026.08.19，Merck/Moderna 公布 INTerpath-001（n=1,137，双盲）期中分析：intismeran autogene（V940/mRNA-4157）+ Keytruda 辅助治疗完全切除 IIB-IV 黑色素瘤，**RFS（主要终点）与 DMFS（关键次要终点）双双达到统计学显著且临床意义显著**——这是首个个体化新抗原疗法（INT）与首个 mRNA 癌症疗法的 Phase 3 阳性，也是首个在辅助黑色素瘤击败 Keytruda 单药的组合。R3"数据读出前不上调评级"的约束按预设 T8 条款解除。

**两个未解悬置**：①HR/效应量未披露（ESMO 10.24 总统研讨会分档：≤0.55 维持 / 0.55-0.7 减半 / ≥0.65 清仓）；②OS 仍在随访（R3 已警示：辅助治疗的终极价值=OS）。MRNA +516-556% YTD / ~130x 年化销售——市值由 NSCLC（INTerpath-002，患者池 10x）期权支撑，估值纪律取代事件纪律成为主要约束。

**平台分化修正**：治疗端确认（Phase 3 级）>> 预防端"高折扣验证"——mFLUSIVA（mRNA-1010）8/5 获批（首个 mRNA 流感疫苗：50-64 全批/65+ 附条件/+26.6% rVE）终结预防端 0/5，但无 ACIP 推荐+RFK/HHS 敌意环境+CMV 前科=商业价值有限。BNTX 侧：CEO 更替（Sahin→Oelkers）、14 项 pivotal 在跑但 BNT122 个体化 Phase 3 仍缺席（T4 维持）。
