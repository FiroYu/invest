# 研究员C：宏观分析 — 2026.06.04

## 核心发现 Top 3

### 1. 超级周期叙事获得主流认可，但"见顶论"同步升温

**牛方证据**：
- Reuters（2026.04）：报道"商品超级周期已经到来"，铜为核心品种
- Robert Friedland（2026.03）：直接反驳衰退论，称"铜超级周期才刚开始"
- BHP：预测2040年数据中心铜需求300万吨/年（当前6倍）
- Goldman Sachs称铜为"AI时代的石油"
- S&P Global：铜需求2040年将达4,200万吨（vs 2030年产量峰值3,300万吨）

**熊方/审慎证据**：
- **StoneX（2026.02）**：直接质疑超级周期叙事——"尽管预测2026年缺口33.3万吨，全球铜库存仍处于数十年来高位"——库存数据与缺口叙事矛盾
- **TD Securities**：铜超级周期"被中断"，短期可能出现疲软期
- **SEI**：超级周期"仍然存疑"，低碳转型投资仍处于早期阶段
- **Goldman Sachs自身**：2026H1均价预测仅$10,710——低于当前现货价$14,000+，暗示投机溢价过高

**判断**：超级周期的**基本面支撑**（供需缺口+品位下降+AI需求）是真实的，但**价格已超前基本面**。当前$14,000+的铜价可能包含30-40%的投机/地缘溢价。中期回调至$11,000-12,000是健康的，不代表超级周期证伪。

### 2. 美元走弱+利率"Higher for Longer"形成矛盾宏观环境

**美元状态**：
- 2026年初至今美元整体走弱（DXY从108+回落至104区间）
- State Street（2026.04）：美元Q2-Q3前景"比预期强得多"，危机环境利好美元
- Investing分析：美元2026年下跌"更多是周期性而非结构性"
- Fed预计2026年降息2次（市场定价）vs Fed指引1次

**对铜价的传导路径**：

```
场景A（利率维持高位）：
利率↑ → 美元↑ → 铜价受压 → 但供给缺口对冲 → 铜价$11,000-13,000震荡

场景B（利率下行）：
利率↓ → 美元↓ → 铜价受益 → 叠加供需缺口 → 铜价突破$15,000

场景C（滞胀）：
油价↑（中东）→ 通胀↑ → 利率被迫维持高位 → 美元↑ → 铜价短期承压
但：铜本身是通胀对冲 → 长期仍偏上行
```

**当前判断**：场景A最可能（概率50%），场景B次之（30%），场景C（20%）。利率环境对铜价**中性偏正面**——即使Higher for Longer，供给缺口的支撑足以抵消强势美元的压制。

### 3. 中国因素：从铜需求引擎到"双面影响"

**中国铜需求现状**：
- 2026年前两月铜进口量同比**下降25%**（Reuters）——引发"中国需求见顶"讨论
- 中国冶炼厂集体减产10%+，政府叫停200万吨新增冶炼产能
- StoneX："中国刺激政策的标题经常误导金属市场——政策信号强，实际传导弱"
- 中国GDP目标维持"5%左右"（2026），但国内需求疲软

**中国结构性转变**：
- 从"铜消费引擎"→"铜加工/冶炼中心"→"铜资源获取者"
- 十五五规划重点从房地产转向新能源（电网+EV+AI基础设施）
- 中国企业（紫金/洛钼）海外矿山扩张加速，争取上游资源控制权

**关键洞察**：中国铜需求的**总量增长放缓**，但**结构正在优化**——房地产用铜占比从35%降至20%，被新能源需求替代。这意味着：
1. 中国铜需求增速放缓但不崩溃（0-2%增长 vs 历史5-8%）
2. 全球铜需求增量来源多元化（美国AI+全球电网+新兴市场EV），不再单一依赖中国
3. 中国冶炼减产实际上**支撑铜价**（减少精炼铜供给）
