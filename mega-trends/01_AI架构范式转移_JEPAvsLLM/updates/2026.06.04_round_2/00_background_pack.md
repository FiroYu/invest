# 背景包 — AI架构范式转移：JEPA vs LLM

> 更新日期：2026-06-04 | Round 2

---

## 一、历史摘要

### 议题起源
Yann LeCun 于 2022 年 6 月发表纲领性论文 *"A Path Towards Autonomous Machine Intelligence"*，首次系统阐述 JEPA（联合嵌入预测架构）构想。核心主张：自回归 LLM 无法真正理解世界、缺乏规划和推理能力，单纯 scaling 无法通向 AGI。替代方案是在潜空间（latent space）中学习抽象表征并预测，而非逐 token 生成。

### 技术演进轨迹
| 时间 | 事件 | 意义 |
|------|------|------|
| 2022-06 | LeCun 发表 JEPA 纲领论文 | 理论框架建立 |
| 2023-06 | I-JEPA 发布（300M 参数） | 首个 JEPA 实例，无需数据增强即达强表现 |
| 2024-02 | V-JEPA 发布 | 扩展到视频理解 |
| 2025-01 | LeCun 离开 Meta，创立 AMI Labs | 从学术研究转向独立商业化 |
| 2025-06 | V-JEPA 2 发布（1B+ 参数） | 零样本机器人规划验证 |
| 2025-09 | LLM-JEPA（NeurIPS 2025 Poster） | **JEPA 首次在语言领域取得突破** |
| 2025-09 | LeCun MIT 演讲 | 预测 JEPA 3-5 年内取代 LLM |
| 2025-12 | VL-JEPA 发布（ICLR 2026） | 50% 参数量超越 GPT-4o/Gemini-2.0 |
| 2026-01 | AMI Labs 成立，MIT TR 专访 | LeCun 公开阐述路线 |
| 2026-03 | AMI Labs 完成 $1.03B 种子轮 | **欧洲史上最大种子轮**，$3.5B 估值 |
| 2026-03 | NVIDIA GTC：World Model 成为主题 | 行业关注度飙升 |
| 2026-05 | LeCun Welch Labs 播客 | 详细对比 JEPA vs 生成式模型 |

### 上轮更新结论（2026.05.25）
- **辩论评级**：维持「技术关注」
- **核心判断**：JEPA 在视觉/机器人领域已确认优势，语言生成仍是"未兑现的承诺"
- **关键矛盾**：$700B Hyperscaler CapEx 全部投向 Transformer/GPU，JEPA 产业采纳为零
- **观察窗口**：2027 年初是关键判断时点

## 二、风险因子映射

### 因子 1：AI CapEx 超级周期（高敏感）
- **当前状态**：$700B Hyperscaler CapEx（+77% YoY），全部投向 Transformer/GPU
- **对 JEPA 议题的影响**：
  - 正面：若 CapEx 回报不及预期，加速行业探索替代架构
  - 负面：巨额投入形成沉没成本和生态锁定，延缓范式转移
  - **关键矛盾**：AMI Labs $1.03B vs 行业 $700B = 0.15% 的资金对抗
- **阈值**：2026 下半年 Hyperscaler 若削减 CapEx 指引，将触发重估

### 因子 2：利率敏感度（低敏感）
- JEPA 议题主要是技术驱动，利率影响间接
- AMI Labs 作为 VC 投资项目，高利率环境可能影响后续融资

### 因子 3：中美脱钩（中敏感）
- LeCun 明确将 AMI 定位为"非美非中的第三极"，巴黎总部
- 中国开源模型（DeepSeek V4、Qwen 3.5）持续强势，但均基于 Transformer
- 若 JEPA 降低对先进制程/GPU 的依赖，芯片出口管制效力可能下降

### 因子 4：私募流动性（低敏感）
- AMI Labs 种子轮 $1.03B 为 VC 融资，非私募资产
- 间接相关：若 IPO 市场恢复，JEPA 相关标的可能更早获得退出通道

## 四、假设体系

### 投资假设（H1-H5）

**H1：JEPA 将在 2028 年前成为视觉/机器人领域的主流架构**
- 状态：进展中
- 证据：V-JEPA 2 零样本规划、VL-JEPA 超越 GPT-4o、GTC 2026 World Model 主题化
- 信心度：70%（从 60% 上调）

**H2：JEPA 在语言生成领域将在 2027 年前取得突破性进展**
- 状态：早期信号
- 证据：LLM-JEPA 在微调场景有效，但非大规模预训练
- 信心度：30%（从 25% 微调上调）

**H3：JEPA 成功将导致 AI 算力需求下降 10-100 倍**
- 状态：未验证
- 证据：参数效率对比支持理论可能，但无生产级验证
- 信心度：20%（维持）

**H4：LLM 生态壁垒将阻止 JEPA 在商业上取代 LLM**
- 状态：强化
- 证据：$700B CapEx 全部投向 Transformer，开源 LLM（DeepSeek V4/Qwen 3.5/Llama 4）持续迭代
- 信心度：75%（从 70% 上调）

**H5：JEPA + LLM 混合方案将成为过渡期主流**
- 状态：趋向共识
- 证据：LeCun 本人承认 LLM 作为"编排器"的角色，LLM-JEPA 混合训练方案
- 信心度：80%（维持）

### 关键判断（K1-K3）

**K1：投资可操作性**
- 当前判断：**不具备直接投资可操作性**。JEPA 纯概念投资标的极少，主要通过"受益于 JEPA 成功"的二级市场标的（边缘芯片、机器人、自动驾驶）间接参与
- 变化：AMI Labs $1.03B 融资使其成为一级市场关注标的，但未上市

**K2：辩论评级**
- 当前评级：**技术关注**
- 维持理由：技术进展加速但产业采纳为零，资金对比悬殊

**K3：时间窗口**
- LeCun 预测 2027 年初行业认识范式转移 → 我们判断偏乐观，实际窗口可能到 2028-2029
- 2027 年初的关键验证点：AMI Labs 首批研究成果、LLM-JEPA 是否扩展到大规模预训练
