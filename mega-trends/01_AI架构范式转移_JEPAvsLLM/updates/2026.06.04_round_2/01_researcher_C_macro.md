# 研究员C — 宏观与传导分析

> 更新日期：2026-06-04 | 角色：宏观研究员

## 核心发现 Top 3

### 发现 1：AI 电力需求已成为美国电网的系统性问题 — 但这利好还是利空 JEPA 取决于叙事主导权

**关键数据**：
- **数据中心已占美国新增电力需求的 50%**（IEA 2026 数据，Fortune 报道）
- 美国数据中心用电量：当前 ~180 TWh → 预计 2030 年 400-600 TWh
- EPRI 预测：数据中心到 2030 年可能消耗美国发电量的 9%-17%（当前约 4%）
- IEA 情景：在高增长情景下，2035 年数据中心电力需求可能达 ~700 TWh
- AI 单次任务耗电可达普通搜索的 **1,000 倍**

**传导分析**：
- **情景 A（JEPA 成功）**：AI 电力需求增速放缓 → 电网压力缓解 → 核电/新能源项目可能推迟 → 电力股承压
- **情景 B（LLM 继续）**：电力需求持续爆发 → 新建核电/天然气项目加速 → Constellation Energy/Vistra 受益，但电网瓶颈可能限制 AI 增长
- **关键矛盾**：当前电力供应紧张**反而是 JEPA 的利好** — 如果算力效率提升 10-100x 可以缓解电网压力，政策制定者和企业有动力支持更高效的架构

### 发现 2：2026 年推理芯片市场正在重构 — 但主要驱动力是 LLM 推理而非 JEPA

**关键趋势**：
- 2026 年被行业称为**"推理之年"**（VAST Data, TrendForce, JPMorgan 均有报告）
- 推理芯片赛道正在从 NVIDIA GPU 垄断走向多元化：
  - 加拿大 Taalas HC1 芯片：16,960 tokens/sec/用户
  - Google TPU、Broadcom 定制 ASIC
  - 中国华为昇腾、寒武纪
- JPMorgan 2026 Tech Trends 报告：推理需求驱动 AI 基础设施持续扩张
- **推理市场规模预计超过训练市场**（2025 年起）

**对 JEPA 的影响**：
- 推理多元化趋势与 JEPA 的"轻量推理"叙事一致
- 但当前推理市场增长主要由 **LLM 推理** 驱动，而非 JEPA
- 如果 JEPA 成功，推理芯片的市场蛋糕可能缩小（因为单次推理更轻），但参与者的利润率可能更高

### 发现 3：开源 AI 模型竞争激烈化 — 但全部基于 Transformer

**2026 年开源格局**：
- **DeepSeek V4**：中国开源旗舰，成本效率极高
- **Qwen 3.5**（阿里巴巴）：Hugging Face 下载量超 10 亿，超越 Llama
- **Llama 4**（Meta）：Scout 和 Maverick 版本，与闭源前沿竞争
- **GLM-5**：智谱 AI
- **Gemma 4**（Google）：开源小模型

**关键洞察**：
- 开源模型全面逼近闭源前沿，且**全部基于 Transformer**
- 这意味着即使"民主化 AI"的目标实现了，它也不是通过 JEPA 实现的
- **Qwen 的成功特别值得关注**：10 亿下载量说明中国开源生态已经非常成熟，且全部在 Transformer 路线上
- DeepSeek 的成本效率（训练成本据报道仅数百万美元）挑战了"JEPA 才能降低成本"的叙事 — Transformer 路线也在变得更高效

## CapEx 传导路径分析

### 路径 1：AI CapEx → 电力瓶颈 → 架构效率溢价
```
$700B CapEx → 数据中心激增 → 电网压力 → 政策鼓励效率 → 利好 JEPA
```
- 当前状态：电网压力已显现（美国新增电力需求 50% 来自数据中心）
- JEPA 受益逻辑：如果 JEPA 能将推理算力需求降低 10x，政策制定者和企业有强烈动机支持
- **但**：这个传导路径需要 JEPA 先证明自己的语言生成能力，而这恰恰是短板

### 路径 2：AI CapEx → 回报质疑 → 替代方案探索
```
$700B CapEx → ROI 不及预期 → 投资者/企业开始探索更高效方案 → 利好 JEPA
```
- 当前状态：ROI 质疑声渐起但尚未成为主流
- 触发条件：2026 下半年 Hyperscaler 削减 CapEx 指引
- 风险：即使 ROI 不及预期，企业可能转向更便宜的 Transformer 方案（DeepSeek），而非 JEPA

### 路径 3：LLM CapEx → 推理成本下降 → LLM 更普及 → JEPA 窗口收窄
```
推理成本年降 10x → LLM API 价格下降 → AI 应用层爆发 → LLM 生态更强
```
- 当前状态：这个路径正在实际发生
- **这是 JEPA 面临的最大宏观阻力** — LLM 变得更便宜、更强、更普及

## 能效对比

| 维度 | LLM 路线（当前） | JEPA 路线（理论） | 差距 |
|------|------------------|-------------------|------|
| 训练能耗 | GPT-4 级 ~50 GWh | 未知（无大规模 JEPA 训练数据） | 无法对比 |
| 推理能耗 | 数据中心 MW 级 | 理论可边缘瓦级运行 | 10-100x |
| 模型大小 | T 级参数 | B 级参数 | 1000x |
| 部署成本 | 需 GPU 集群 | 理论可 CPU/NPU 运行 | 显著 |
| 数据需求 | 万亿 token | 千万级多模态样本 | 100x |

**关键问题**：以上对比仅适用于视觉/机器人场景。在语言生成场景，JEPA 没有可对比的数据。

## 宏观影响情景

### 情景 A：JEPA 成功 + CapEx 削减（概率 10%）
- AI 电力需求增速放缓
- 边缘芯片受益，高端 GPU 受损
- HBM 需求见顶
- 电网投资可能推迟

### 情景 B：混合方案 + CapEx 维持（概率 50%）
- AI 电力需求继续增长但增速可能放缓
- GPU 仍为主力，但 NPU/ASIC 份额提升
- 推理芯片多元化
- 数据中心建设继续但更注重效率

### 情景 C：LLM 继续 + CapEx 加速（概率 40%）
- AI 电力需求持续爆发
- 核电/新能源项目加速
- GPU 供不应求持续
- JEPA 沦为学术项目
