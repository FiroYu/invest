## 核心判断（R2 基线，05.25）

Volt Typhoon（伏特台风）已被美国CISA、FBI、NSA联合确认——国家支持的攻击者已预置在美国关键基础设施系统中（能源、水务、通信、交通），目的是在战时实施破坏。这标志着网络安全从"IT预算项目"转变为"国家安全支出"的范式转移。

全球网络安全市场2025年规模 $219-255B，预计2030年增长至 $335-580B（CAGR 7-15%）。国防网络安全领域增速更为迅猛，从2025年 $20.35B增长到2033年 $54.46B（CAGR约13%）。关键基础设施保护市场从2025年 $154B增长到2030年 $197B。

这一议题的核心问题是：**国家级网络攻击从"间谍活动"升级为"战时破坏准备"，将如何重塑全球网络安全投资格局？**

## 关注模型

需要持续追踪的动态指标：

1. **企业网络安全预算增速** — 网络安全支出占IT总预算的比例是否从当前5-15%向20%+移动
2. **国家级网络攻击频率** — APT组织活动频率、攻击复杂度演变
3. **保险行业网络风险定价** — 网络保险费率、承保条件变化，反映风险的量化
4. **监管合规要求升级** — NIS2、DORA、SEC网络安全披露等法规的实施影响
5. **关键基础设施暴露面** — IT/OT融合进度、SCADA系统联网比例

## 投资含义（R3 更新）

- **R3 上调至「有条件通过」**：四重共振（财报+并购+监管+威胁）验证可投资性；但估值约束使评级附条件——**估值纪律**（回调 −15-25% 分批建仓，不追高）

## 最新更新 — 2026.07.10（Round 3 CIO 综合）

### 评级：积极关注 → 有条件通过（上调一级）

四重共振验证 R2 结构性多头；但估值约束使评级附条件。**条件即估值纪律**——不在当前追高（CRWD 22x PS、FTNT YTD +86%），设定回调 −15-25% 分批建仓。

### 头号裁定：AI 攻防不对称恶化是核心 alpha

R2 把 AI 框为"双刃剑"过于中性。R3 数据证明**结构不对称在恶化**——攻击者享受 AI 杠杆（钓鱼 +1,265%、prompt 注入 73% 部署、15 分钟漏洞窗口），防御者仍需逐企业定制。短期 AI CapEx 挤压安全预算（17x 比例），中期被压制需求释放。AI 驱动防御新锐（SentinelOne/Wiz-Google）是增长最快子赛道，但警惕大厂平台吞并。

### 情景概率（A/B/C/D）

| 情景 | 概率 | 描述 |
|------|------|------|
| **A 基准**（+15-25% 维持增长） | **50%** | 财报延续 +20%+，回调 -10-15% 企稳续创新高 |
| B 加速（系统性事件催化 +30-50%） | 15% | Volt Typhoon 类实际破坏事件 |
| C 估值回归（-20-35% 回调） | 25% | 指引放缓 + 利率不降；ZS -31%/NET -23% 的全面版 |
| D 商品化（大厂吞并独立厂商） | 10% | 慢变量，2027+ 显现 |

**CIO 注**：C 情景 25% 是"有条件通过"（非"通过"）的核心原因。

### 三层组合配置（目标 7.5%）

- **确定性层（4.0%）**：CIBR ETF 2.0%（底仓分散，当前建 1/3）/ PANW 1.0%（平台化赢家，回调 −20%）/ FTNT 1.0%（盈利能力 + 13x PS 相对合理）
- **高 beta 层（2.5%）**：CRWD 1.0%（**当前不买**，−25% 标仓）/ ZS 0.5%（FCF 企稳后）/ NET 0.5%（AI 收入证实后）/ OKTA 0.5%
- **投机对冲层（1.0%）**：SentinelOne 0.5%（AI 弹性）/ BAH 0.5%（国防网安）/ HiddenLayer（观察 IPO）
- **初始建仓仅 2-3%**，余下通过回调分批
