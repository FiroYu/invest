## 2. PQC 迁移的宏观传导

### PQC 迁移的经济规模

| 维度 | 估计 |
|------|------|
| 全球企业 PQC 迁移成本 | >$150 亿（到 2030） |
| 企业网络安全预算占比 | 3-7%（PQC 迁移高峰期） |
| 迁移周期 | 大企业 12-15 年 |
| 影响协议/系统数 | 比 AES/SHA 迁移更复杂（更多协议、系统、依赖） |

### PQC 迁移时间线紧迫性

| 里程碑 | 时间 | 紧迫性 |
|--------|------|--------|
| NIST 标准发布 | 2024.08（已完成） | — |
| NSA CNSA 2.0 支持+偏好 | 2026 | **当前** |
| G7 声明 PQC 规划年 | 2026 | **当前** |
| 加拿大政府启动 PQC 迁移计划 | 2026.04 | **当前** |
| Google 完成 PQC 迁移 | 2029 | 高 |
| NSA CNSA 2.0 独占使用 | 2030 | 极高 |
| NIST 弃用传统加密 | 2030 | 确定 |
| 美国联邦系统 PQC 迁移目标 | 2035 | 确定 |

### PQC 迁移受益链条

| 受益层 | 代表 | 逻辑 |
|--------|------|------|
| PQC 算法/IP | PQShield, QuSecure, SEALSQ | 算法授权 |
| 网络安全平台 | Palo Alto (PANW), CrowdStrike (CRWD) | 集成 PQC 到安全产品 |
| 云平台 | Google, AWS, Azure, Cloudflare | PQC 基础设施服务 |
| 证书/密钥管理 | Entrust, DigiCert | 证书重新签发 |
| 硬件安全模块(HSM) | Thales, Utimaco | PQC 兼容 HSM |
| 嵌入式/IoT | 芯片厂商 | PQC 兼容芯片设计 |

**关键洞察**：Google 将 PQC 迁移截止日从 2035 提前至 2029，Cloudflare 同步 2029 目标。这比 NIST 2030 弃用还早 1 年，反映头部科技公司对"先存储后解密"攻击的紧迫感。PQC 迁移不是"量子计算何时实用化"的问题，而是"现在存储的加密数据在量子时代是否安全"的问题。

## 3. 宏观影响维度

### 量子计算与能源

| 维度 | 评估 |
|------|------|
| 当前量子计算机功耗 | ~25kW（Google D-Wave 级别），约等于大型 HVAC |
| 稀释制冷机需求 | 超导量子需要 ~15mK 极低温，能源密集 |
| 与 AI 数据中心对比 | 量子功耗远小于 GPU 集群，但数据中心需要额外制冷基础设施 |
| 长期趋势 | 量子计算单位计算能效可能优于经典计算，但扩展后的总能耗取决于规模 |

**判断**：量子计算在能源维度不是瓶颈。单台量子计算机功耗远小于 GPU 集群。但超导路线需要稀释制冷机（$500K-$1M/台），这构成资本开支而非能源约束。

### 量子计算与国家安全

| 维度 | 评估 |
|------|------|
| 加密破解风险 | RSA-2048 需 ~4,000 逻辑量子比特，当前仅 100 级，差距仍大 |
| "先存储后解密"威胁 | **正在发生**（WEF 2026 年 2 月确认） |
| 量子传感 | 军事应用（导航、探测）可能比量子计算更早实用化 |
| 量子通信 | 中国在天衍量子网络领先，美国通过 PQC 迁移应对 |
| 情报机构紧迫性 | NSA CNSA 2.0 → 2030 年国家安全系统完全迁移 |

### CHIPS 法案的战略意义

| 公司 | 金额 | 路线 | 战略价值 |
|------|------|------|---------|
| IBM | $10 亿 | 超导 | 量子晶圆厂（Poughkeepsie），300mm 工艺 |
| GlobalFoundries | $3.75 亿 | 多路线 | 国内量子芯片代工厂 |
| Quantinuum | ~$1 亿 | 离子阱 | 美国离子阱量子计算 |
| D-Wave | ~$1 亿 | 退火 | 优化问题专用 |
| PsiQuantum | ~$1 亿 | 光量子 | 光量子计算 |
| Atom Computing | ~$1 亿 | 中性原子 | 可扩展中性原子 |
| 其他 3 家 | 共 ~$1 亿+ | 多路线 | — |

**关键洞察**：CHIPS 法案对 5 条技术路线同时下注，说明**政府也不确定哪条路线会赢**。这是理性的投资组合策略，但也意味着单一路线获得的资金不如集中于一条路线多。

## 4. 宏观风险矩阵

| 风险 | 概率 | 影响 | 传导路径 |
|------|------|------|---------|
| Q-Day 提前（2030 前破解 RSA） | 低（<10%） | 极高 | 全球加密恐慌→PQC 迁移加速→安全股暴涨 |
| PQC 迁移成本超预期 | 中 | 中高 | 企业 IT 预算挤压→PQC 服务商受益但采用放缓 |
| 中美量子冷战升级 | 高 | 高 | 技术封锁→量子出口管制→生态割裂 |
| 量子计算冬天（资金退潮） | 中 | 高 | 概念股暴跌→技术进展放缓 |
| 经典计算追赶削弱量子价值主张 | 中低 | 中 | GPU/TPU 持续进步→量子优势窗口收窄 |

## 5. 宏观结论

1. **PQC 迁移是最确定的投资主题**：不依赖于量子计算何时实用化。Google/Cloudflare 2029 目标 + NSA 2030 目标 + NIST 2035 禁令 = 确定性收入流
2. **中美量子竞赛是双刃剑**：推动政府资金投入（CHIPS $20 亿），但也带来技术封锁和生态割裂风险
3. **"先存储后解密"攻击正在发生**：当前加密的敏感数据在未来量子时代可能被破解，这是 PQC 迁移紧迫性的核心论据
4. **宏观环境对量子投机股不利**：Higher for Longer 利率环境 + AI CapEx 争夺资金 = 量子概念股面临估值压缩
5. **Quantinuum IPO 是宏观测试**：将测试公开市场对高估值亏损量子公司的容忍度
