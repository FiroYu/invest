## 4. 估值泡沫信号

| 信号 | 状态 |
|------|------|
| P/S 极端值 | IONQ ~100x / QBTS ~800x / Quantinuum ~460x → **高度泡沫** |
| 收入增速 vs 估值增速 | IonQ 收入增长 755% 但市值增长更多 → **估值领先基本面** |
| 集体暴涨 | 5 月 21 日 CHIPS 法案宣布日量子股集体暴涨 10-20% → **投机情绪驱动** |
| 分析师分歧 | Jefferies 2025 年底给 IONQ/RGTI/QBTS 目标价远低于当时市价 → **市场不认同卖方定价** |
| Barron's 警告 | 集体市值 ~$55B vs 季度总收入 ~$26M → "泡沫" |
| IPO 估值下调 | Quantinuum 从 $200 亿降至 $14.3 亿 → **公开市场重新定价** |

**结论**：纯量子概念股估值仍处于高度投机区间。Quantinuum IPO 的市场接受度将是关键测试——如果 IPO 后跌破发行价，可能触发全行业估值重置。
