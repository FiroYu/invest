## 核心争议点

### 正方（量子时代即将到来）
- Quantinuum 94逻辑量子比特 + IonQ量子网络突破 + IBM Nighthawk 120Q

- PQC迁移时间线提前：Google 2029 / NSA 2030

### 反方（过度炒作/进展缓慢）
- 通用容错量子计算仍需3-5年（IBM 2029），路线图有延迟历史
- 量子概念股估值极端：IONQ P/S ~100x / QBTS ~800x / Quantinuum ~460x
- 五大路线未收敛（CHIPS同时投注5种架构）
- 无独立验证的商业量子优势案例
- 经典计算追赶：JUPITER 50Q量子模拟
- Gil Kalai/Scott Aaronson等顶级学者质疑量子计算可扩展性

### 当前共识
- PQC迁移是确定性事件，不依赖量子计算何时实用化
- 量子计算与AI是互补关系
- 纯量子概念股处于高度投机阶段，控制仓位2-3%
- Quantinuum IPO（6/4）是行业估值锚点
