## 一句话判断
> 量子计算进入早期商业化萌芽期（2026年IonQ年化收入$260-270M，Quantinuum IPO $14.3B）。投资逻辑分三层：**PQC迁移**确定性进一步增强（Google 2029 / NSA 2030 deadline）；量子模拟正在验证（IBM承诺2026量子优势）；纯量子概念股估值仍极端（P/S 100-800x）。通用容错量子计算仍需3-5年。与AI是互补而非替代。评级：**积极关注**。

## 为什么重要
- **人类影响**：量子计算一旦破解RSA/ECC，全球金融系统、互联网安全、军事通信将面临系统性重构
- **经济影响**：McKinsey预测2035年量子经济影响$7200亿-$1万亿，但当前实际收入仅$10-40亿
- **时间敏感度**：2025年被McKinsey定义为"量子元年"；NIST已发布PQC标准，迁移窗口已打开

## 核心争议点

### 正方（量子时代即将到来）
- Quantinuum 94逻辑量子比特 + IonQ量子网络突破 + IBM Nighthawk 120Q
- IonQ Q1收入+755% YoY，年化指引$260-270M，RPO $470M
- CHIPS法案$20亿 + Quantinuum $1.46B IPO = 产业资本涌入
- PQC迁移时间线提前：Google 2029 / NSA 2030
- IBM承诺2026年量子优势

### 反方（过度炒作/进展缓慢）
- 通用容错量子计算仍需3-5年（IBM 2029），路线图有延迟历史
- 量子概念股估值极端：IONQ P/S ~100x / QBTS ~800x / Quantinuum ~460x
- 五大路线未收敛（CHIPS同时投注5种架构）
- 无独立验证的商业量子优势案例
- 经典计算追赶：JUPITER 50Q量子模拟
- Gil Kalai/Scott Aaronson等顶级学者质疑量子计算可扩展性

### 当前共识
- PQC迁移是确定性事件，不依赖量子计算何时实用化
- 量子计算与AI是互补关系
- 纯量子概念股处于高度投机阶段，控制仓位2-3%
- Quantinuum IPO（6/4）是行业估值锚点
