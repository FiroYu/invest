## 五、最可能的失败模式 Top 3（更新）

### #1：债务驱动 CapEx 周期反转"电信泡沫 2.0"——**20-25%**（维持 R3 上限）

- 触发：2027 指引低于卖方共识 15%+（K16）；CoreWeave $4.2B 墙处理失败/违约（K13）；任一 IG 发行人流标/利差 >50bp（K11）；10Y 突破 5.25%（K18）
- 传导：再融资成本↑ → neocloud 违约/GPU 抵押品抛售 → GPU 二级二次下挫 → 折旧重估+CapEx 冻结 → NVDA/AVGO 订单与 CoWoS 需求同塌
- CIO 注：GPU 与光纤的耐久性差异（3-6 年 vs 数十年）使"过剩救下一代"不成立（魔鬼类比采信）——出清残值近零

### #2：推理商品化+转卖方触发 GPU 过剩"通缩陷阱"——**22-28%**（R3 20-25% 上移）

- 触发：Meta Compute 正式商用计费（K15）；第二家跟进；H100 中位 <$1.5 持续 2 周（K4）；B200 现货松动
- 传导：API 价格战 → 推理毛利坍塌 → neocloud 租金不及偿债覆盖 → 抵押 GPU 出清 → 新旧世代共振下行
- CIO 注：当前 API 层与裸算力层分裂（旗舰稳/中位租金涨）——触发依赖 Meta Compute 定价落地，**9 月为观测窗口**

### #3：盈利质量冲击——折旧年限重估/减值——**10-15%**（新入，替代物理约束）

- 触发：任一 Hyperscaler 正式下调 GPU/服务器折旧年限或计提减值（K14）；SEC 问询折旧会计
- 传导：折旧重估 → 盈利下修 → 估值中枢下移 → 股权融资能力受损 → 反噬 CapEx 融资链（与 #1 合流）
- CIO 注：Amazon 6→5 年回撤是首个实体证据；NVDA "justified cheap" 论证依赖 6 年折旧假设（魔鬼 Cisco 类比采信一半——估值论证确有此依赖，但 Cisco 类比的时点不可知）
