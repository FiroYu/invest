## 三、盲区清单

### 盲区 1（★最严重）：A/B/C 均未正面回应"Meta 转卖方"信号

Meta 2026.07.01 宣布 Meta Compute 对外售算力——这是 Round 3 窗口内最重要的需求侧事件。C 在时间线中仅以一句"ROI 路径多元化"带过（正面解读），A 和 B 完全未提及。魔鬼将其作为核心反方论据 R4（证据强度：强，最高优先级）。

**为何严重：** 当最大 GPU 买家（Meta 年购 ~$25-40B AI 芯片）开始出售算力时，这对 neocloud 需求（CoreWeave 同日 -13%）、GPU 二级市场价格（H100 spot）、以及 Hyperscaler CapEx 指引的可持续性都有直接含义。如果 Meta 发现自身算力过剩，其他 Hyperscaler 是否也有类似情况？

**PM 要求：** Round 4（或 8/26 财报后的即时复查）必须正面分析 Meta Compute 的①算力规模、②定价策略、③对 neocloud 竞争格局的影响。

### 盲区 2：NVDA 回租 neocloud 产能——需求不足还是 SLA 补充？

魔鬼引用 gentic.news 报道 NVDA 从 neocloud 回租 GPU 产能。如果属实，这意味着 neocloud 无法将 GPU 库存卖给终端客户，NVDA 充当"最后买家"。A/B/C 均未提及此信号。

**PM 要求：** 核实 NVDA 回租的真实性。如果确认，需要评估：①回租规模；②是否构成 vendor financing 循环风险（类似 Round 2 的 NVDA→CoreWeave→Nebius 循环）；③回租的 GPU 去向（自用研究？转售？）。

### 盲区 3：Burry 折旧框架（GPU 寿命 2-3 年 vs 折旧 5-6 年）

魔鬼 R1 引用 Michael Burry 框架：GPU 经济寿命 2-3 年（技术迭代），但 Hyperscaler 折旧年限 5-6 年。如果折旧年限被强制缩短至 3-4 年，$176B 累计折旧少计将在 2026-2028 集中暴露。A/B/C 均未对此框架进行评估。

**PM 要求：** 在 8/26 NVDA Q2 财报和 7 月下旬 Hyperscaler Q2 财报中，重点检查：①是否有 Hyperscaler 宣布缩短 GPU 折旧年限；②资产减值信号；③折旧政策变更对 EPS 的影响。

### 盲区 4：Token 支出指数"急剧失速"

魔鬼 R3 引用 The Silicon Data LLM Token Expenditure Index 在 4-5 月飙升后"急剧失速"。如果 Token 消费增长正在放缓（而非加速），则推理需求增长的核心假设（H3）可能被高估。A 引用 Google 16B tokens/min（环比 +60%）和 Amazon Bedrock Q1 tokens > 历史总和——但这是供给侧处理量，不等于需求侧支出。

**PM 要求：** 区分 Token 处理量（供给指标）和 Token 支出指数（需求指标）。如果两者背离（处理量增长但支出停滞），说明 API 定价下降速度已超过用量增长——这是定价权毁灭的先行指标。

| 关联课题 | 传导路径 | 方向 | 强度 | 是否需更新 | 关键逻辑 |
|---------|---------|:----:|:----:|:---------:|---------|

| **#21 供应链** | CapEx 断裂 + 中美脱钩升级→供应链碎片化加速→双轨供应链成本上升 | 负 | 强 | 是 | 台海局势升级 + AI 芯片出口管制扩大化 = 供应链分化加速 |

### 对 #08 AI Agent 的重点传导分析

**如果 CapEx 断裂（概率 15%），对 #08 的传导路径：**

1. **推理成本曲线变化：** 当前推理成本年降 ~10x 的核心假设（H3）依赖于 GPU 供给持续增长 + 软件优化。如果 CapEx 断裂导致新 GPU 供给放缓，推理成本年降率可能从 10x 降至 3-5x（参考 Presenc AI 预测）。
2. **Agent 经济性冲击：** AI Agent 每查询消耗 10,000-100,000 tokens（agentic loop + tool use + reasoning chain）。如果 token 单价不再快速下降，Agent 每查询成本将从 $0.001 级别回到 $0.01-0.05 级别——对企业采用率有直接负面影响。
3. **但存在对冲：** Meta Compute 如果以低价释放"过剩算力"，短期反而降低 Agent 推理成本。这种"过剩红利"窗口可能持续 6-12 个月，直到 neocloud 行业完成洗牌。
4. **净判断：** CapEx 断裂对 #08 是**中长期负面**（推理成本不再快速下降），但**短期可能因算力过剩反而有利**（Meta/xAI 低价释放算力）。#08 课题需要将"推理成本下降速度"作为核心监测指标。
