## 二、最可能的失败模式（Top 3）

### 失败模式 1：JGB 失控 → 财政恐慌 → 评级展望负面 → 金融层全面回撤
- 描述：2027 财年预算（12 月-1 月）显示普通国债发行 >¥36T+国防/育儿支出失控 → 40Y/30Y 拍卖需求断裂 → 10Y 3.5%+ → 高川被迫推迟支出或增税（政治自杀）→ 评级展望负面 → 寿险被迫减持股票补久期 → 日经 -20%
- 触发条件：发行计划超预期；BOJ 缩表加速；美国 10Y 再上 5.5%
- 传导：JGB → 银行/保险（债券持仓浮亏+保费错配）→ TOPIX 全线 → carry 平仓（日元急升）→ 全球
- 概率：20%
- 预期损失：-25%（议题组合）

### 失败模式 2：日元 carry trade 大平仓 → 全球风险资产去杠杆 → 议题双杀
- 描述：160 干预+BOJ 意外鹰（重建独立性）双触发 → USD/JPY 三周 158→145 → 全球 carry 头寸平仓 → 日经 -15%/美股高 beta -10% → 外资从日股撤退（卖最流动的资产）→ 日经/TOPIX 双杀 → 银行股也跌（风险偏好）
- 触发条件：BOJ 12 月加息 50bp 或 10.30 意外鹰；美国数据恶化使 Fed 预期反转
- 传导：汇率 → 全球 equities → 日本金融层（β 通道，与利率逻辑无关）
- 概率：15%
- 预期损失：-20%（议题组合）

### 失败模式 3：CPI 第二波哑火 + 消费固化 → "regime change"叙事降温 → 估值中枢回落
- 描述：10-12 月 CPI 因补贴恢复/能源回落停在 1.8-2.0%（不再上冲）；消费第 10-12 个月负增长；BOJ 停在 1.25% 至 2027 年中 → "利率正常化"定价（银行股 10-12x）失去上修燃料 → 日经在 65-70k 横盘消化 → 相对收益归零
- 触发条件：中东缓和（油价 <$85）；政府再推电费补贴；春斗 2027 预期回落至 4% 以下
- 传导：CPI → BOJ 预期 → 金融层估值 → 议题整体
- 概率：30%（**最高概率的失败模式，但杀伤最小**）
- 预期损失：-8%（机会成本型）

## 三、对研究员的预设质疑

1. A 若引用"三大行创纪录"：请拆分经常收益 vs 资产出售浮盈 vs 汇率换算——若经常收益占比 <70%，"利率敏感"结论降档
2. B 若给 12 月加息 30% 概率：分裂投票（7-2）后，连续加息需要委员会翻转 2 票——给出翻转路径再谈概率
3. C 若用"日资回流 >¥20T/年"吓美国市场：请给出回流=卖美债的实证（2022-24 年日资卖过吗？买盘结构决定冲击大小）
4. 所有人：把"家庭股票超保险年金"的口径核对清楚（含 NISA 税制变化的结构性影响 vs 主动风险偏好迁移），这是"大迁移"叙事的核心证据，口径错了结论全错
