# 现代模拟计算与RRAM存算一体范式转移 — 技术深度分析

## 1. 术语重新定义："模拟"是类比，不是连续

Maley（2024, WIREs Cognitive Science）澄清的概念基础：Analog 的词根是 Analogy（类比）——不经二进制符号抽象，把数学问题直接映射到物理系统，靠物理定律给出答案。三堆苹果各五颗并起来数出十五颗就是模拟乘法。连续性既非必要也非充分。

**现代 vs 传统模拟计算的三维区分**（2026-11 综述框架）：

| 维度 | 传统模拟计算 | 现代模拟计算 |
|------|------------|------------|
| 任务 | 微分方程求解 | AI/6G 时代的矩阵计算（MVM、矩阵方程、求逆） |
| 硬件 | CMOS 模拟电路（运放/积分器） | RRAM 等忆阻器纳米器件 |
| 可行性 | 低精度、难扩展 | 高精度（位切片）+ 可扩展（分块）工程路径 |

## 2. 物理原理：三条定律构成计算原语

1. **欧姆定律 = 乘法**：I = G×V。乘数一个编程为器件电导 G，另一个作为电压 V 加载，输出电流天然是乘积
2. **基尔霍夫电流定律 = 求和**：多行器件电流汇入同一列导线，总电流 = 各支路之和。一列的完整乘加（MAC）在汇流瞬间一次性完成
3. **负反馈闭环 = 解方程**：运放闭环反馈网络通电后在纳秒级自发收敛到物理平衡态，平衡点电压即 Ax=b 的解——**一步测量替代 GPU 几十至百次迭代，且响应时间与矩阵维度无关**（公司口径 <100ns）

三个核心原语（解微分方程 / 解矩阵方程 / MVM）共享加法器、乘法器、积分器算子，数学上互相贯通（微分方程离散化→矩阵方程；矩阵方程可迭代 MVM 逼近或闭环一步测出），构成统一计算谱系。

## 3. 为什么 RRAM（忆阻器）是解锁点

传统电路里可实时变化的物理量只有电压和电流，电阻制造即固定——乘法的第二输入没有载体。RRAM 的电导可通过电脉冲精确改写且断电保持（非易失），为集成电路提供了第三种可编程物理变量"电导"。

**密度优势**：RRAM 是双端纳米器件（几十纳米），1000×1000 交叉阵列 = 100 万个原位模拟乘法器集成在极小面积。对比：2016 年 JSSC 上的 65nm CMOS 模拟芯片仅容纳 4 个积分器和 8 个乘法器；CMOS 运放面积下集成 100 万乘法器无物理可行性。此外 RRAM 可在标准 CMOS 后道工艺集成，28nm 乃至 22nm 成熟制程即可制造——这是"绕开 EUV"叙事的硬件根基。

## 4. 精度突破（2025-10 Nature Electronics）：从 3% 到 1e-7

模拟计算的"阿喀琉斯之踵"一直是器件涨落导致的精度损失。解法是**移植早期数字计算机的位切片（bit-slicing）思想**：

- 放弃不可靠的连续电导态，每器件只用经过充分验证的 **8 个离散电导态（等效 3bit）**
- 8 个 3bit 阵列切片拼接 → **24 位定点精度**
- 算法分层：低精度求逆定方向 → 高精度乘法逐步消残差 → 3 次迭代相对误差 1e-4，后续收敛 1e-7（追平 FP32）
- 位切片纵深扩展理论上无精度上限（加切片数与迭代步数）
- **BlockAMC** 分块算法把大矩阵拆为硬件可承载子块，实测 512×512

配套的数模混合架构原则："矩阵归模拟，逻辑归数字"——矩阵运算走微型模拟核，非线性算子（开方/三角）、核间与跨芯片传输走数字通道。位切片红利使外围 ADC 只需 6-8bit 分辨率、10MHz 采样率的规格（放宽精度/采样率大幅换功耗与面积），这是"接口开销不吞掉模拟收益"论证的关键——**注意：此论证仍出自当事团队，无第三方验证**。

## 5. 与主流存算一体（CIM）的路线区分

| | 主流 CIM（边缘推理） | 本路线（模拟矩阵求解） |
|---|---|---|
| 介质 | SRAM(54%)/Flash(15%)/RRAM(28%)（2025 出货占比） | RRAM 电导阵列 |
| 核心运算 | MVM（矩阵向量乘，做推理加速） | 闭环矩阵方程求解/求逆 |
| 市场 | 端侧 AIoT（2025 全球 8.9 亿颗、48.7 亿美元） | 数据中心/科学计算/6G 基站 |
| 竞争者 | GPU/NPU 边缘方案、各家 CIM 初创 | GPU 迭代求解（无直接专用硬件对手） |
| 成熟度 | 已量产（知存千万级出货、后摩 M50、小米玄戒 O100 近存计算） | 原理样机（512×512）→工程样机过渡 |

两者共享器件工艺链（RRAM 制造、交叉阵列），但目标市场、竞争格局、验证节点完全不同。A股"存算一体概念"主要映射前者。

## 6. 工程挑战（反方视角）

1. **器件物理**：电导漂移（drift）、读写噪声、循环耐久性（endurance）在大阵列、长时间下的统计表现，公开数据不足
2. **良率与一致性**：100 万交点中每个都需可编程到 8 个离散态之一，坏点映射/冗余设计的面积代价未知
3. **温漂与老化**：模拟系统对环境敏感，数据中心级可靠性标准（FIT rate）未验证
4. **软件生态为零**：编译器、算子库、PyTorch 接口、调试工具——历史上 ISA/生态壁垒杀死过的"更快硬件"不止一家
5. **接口开销的放大效应**：BlockAMC 分块后，块间搬运与 DAC/ADC 次数随分块数增长，大矩阵下的端到端（含转换与搬运）性能才是真考验，论文口径多为核内性能
6. **数字阵营同步进化**：GPU 张量核 + preconditioner 等算法优化也在压迭代次数；"够用的数字方案"是最强对手（RNN/Capsule Net 教训）

## 7. 竞争性非常规计算路线

- **热力学计算**（Normal Computing CN101）：物理系统弛豫求解，与闭环负反馈电路在拓扑上同构（孙仲标注"Another name, same circuit"），商业路径更偏 EDA+IP
- **光计算/光子矩阵**：光强干涉做 MVM，与 #02 光学互联议题相关
- **数字存内计算**（d-Matrix 等）：保留数字精度优势的近存方案，工程风险更低但天花板也更低
