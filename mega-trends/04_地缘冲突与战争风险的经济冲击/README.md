## 一句话判断
> 地缘风险已从"低概率事件"变为"结构性常态"。全球军费$2.89万亿连增11年，北约5%GDP目标正式通过（但实际执行率预计60-70%）。2026年伊朗战争后霍尔木兹海峡通行仅恢复15-20%，Brent维持$85-100。央行购金创纪录（43%计划增持）但BIS警告杠杆闪崩风险。投资核心：构建"结构性+事件驱动"双轨组合，网安穿越周期，防务龙头等回调入场，黄金$4,200以下加仓。

## 辩论评级：有条件通过（条件收紧）

**维持理由**：军费增长、央行购金、供应链重构三项结构性趋势确认。
**收紧原因**：(1) 美伊和谈进入"临门一脚"，Q3可能全面降温；(2) BIS杠杆闪崩警告引入金价见顶硬证据；(3) 北约5%目标财政可行性受CBO/IMF/学术研究三方质疑。
**升级条件**：美伊谈判破裂 + 安卡拉峰会提交可信5%路线图 + 金价守住$4,200
**降级条件**：美伊核协议Q3达成 + 金价破$4,000 + 欧洲主要国家退出5%承诺
